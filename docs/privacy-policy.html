히유(Pheeeew) 개인정보 처리방침

시행일: 2026년 10월 28일, 최종 수정일: 2026년 9월 29일

Byeolter(이하 “운영자”)는 Google Play와 App Store에 “히유”로 등록된 Pheeeew 앱(이하 “앱”)을 운영하며, 앱을 이용하는 사용자의 개인정보를 중요하게 생각합니다. 운영자는 「개인정보 보호법」 등 적용되는 법령과 Google Play 및 App Store 관련 정책을 준수하기 위해 다음과 같이 개인정보 처리방침을 공개합니다.

이번 개정에서 달라지는 점
음성 녹음을 수집합니다. 이전 방침은 녹음 내용을 저장하거나 전송하지 않는다고 안내했으나, 이번 개정부터 사용자가 감정에 녹음을 첨부하면 그 음성 파일이 운영자의 저장소에 보관됩니다. 또한 앱 오류와 사용 흐름을 분석하기 위한 외부 서비스(PostHog, Sentry)를 도입하고, 여러 사용자가 함께 쓰는 그룹 기능이 추가됩니다.
핵심 요약
앱은 회원가입, 광고, 결제 기능을 사용하지 않고 이름, 이메일, 전화번호를 받지 않습니다. 감정을 남기면 사용자가 지도에서 직접 찍은 위치와 메모 또는 녹음이 운영자 서버에 저장됩니다. 기기의 실제 위치는 전송하지 않습니다. 서버는 기기마다 무작위 식별자를 만들어 저장하며 이 값으로 같은 기기가 남긴 감정을 구분합니다. 다른 사용자에게는 기기 식별자를 보여 주지 않습니다. 그룹에 참여하면 어느 기기가 어느 그룹에 속하는지를 서버가 저장합니다. 지도 화면을 위해 OpenFreeMap에 지도 스타일과 타일을 요청합니다.

1. 처리하는 개인정보와 이용 목적

항목이용 목적처리 시점과 방법보유 기간
기기의 대략적, 정확한 위치, 위치 정확도, 측정 시각 지도에 현재 위치를 표시하고, 감정을 남길 수 있는 범위(주변 500m)를 정하는 기준으로 사용 사용자가 현재 위치 기능이나 감정 남기기를 실행하고 위치 권한을 허용한 경우 기기 운영체제의 위치 서비스를 통해 단발성으로 접근 앱 메모리에서만 유지하며 새 위치로 대체되거나 앱 프로세스가 종료되면 삭제. 실제 위치는 서버로 전송하지 않음
사용자가 지정한 감정 위치(위도, 경도) 지도에 감정을 스탬프로 표시 감정 등록 시 서버에 저장. 사용자가 지도에서 직접 찍은 지점이며, 앱은 현재 위치에서 반경 500m 안에서만 고를 수 있게 제한. 기기의 실제 좌표는 전송하지 않음 삭제 요청 또는 신고 누적으로 가려질 때까지 데이터베이스에 보관
감정 상태(답답함, 짜증, 지침, 좌절, 화남 중 하나), 스탬프 회전 각도 지도와 목록에 감정을 구분해 표시 감정 등록 시 사용자가 선택한 값을 저장 위와 같음
감정 메모(최대 200자), 서버가 생성한 임의 닉네임, 작성 시각 감정 내용 표시 사용자가 입력하거나 서버가 생성해 감정 등록 시 저장. 닉네임은 감정마다 새로 생성되며 사용자가 정한 이름이 아님 위와 같음
음성 녹음 파일과 파일 형식, 파일 크기, 업로드 시각 사용자가 메모 대신 목소리로 감정을 남기고, 감정 상세 화면에서 다시 들을 수 있도록 제공 사용자가 녹음을 첨부해 감정을 등록할 때 앱이 운영자가 발급한 일회용 업로드 주소로 Amazon S3에 직접 전송. 서버는 파일 자체를 거치지 않고 저장 위치만 감정에 연결. 메모와 녹음은 함께 등록할 수 없음 연결된 감정을 삭제해도 녹음 파일은 저장소에 남습니다. 삭제를 원하시면 제8조의 방법으로 요청해 주십시오
기기 식별자(서버가 생성한 무작위 UUID), 플랫폼 구분(Android/iOS), 등록 시각 같은 기기가 남긴 감정을 구분하고, 이모지, 신고, 차단, 그룹 참여가 기기별로 한 번만 반영되도록 보장 기기 등록 시 서버가 생성해 저장. 기기 고유 번호(광고 ID, IMEI, MAC 주소 등)를 받거나 저장하지 않음 앱을 삭제해도 서버의 기기 정보는 남음. 재설치하면 이전 기기와 연결되지 않는 새 기기로 등록됨
인증 토큰(서버가 생성한 무작위 값의 해시) 기기 인증 유지 기기 등록 시 서버가 생성해 해시만 저장. 원문은 저장하지 않음 기기 정보와 함께 보관
그룹 정보(그룹 이름, 설명, 초대 코드, 스탬프)와 참여 기록(기기 식별자, 역할, 참여 시각, 나간 시각) 같은 그룹에 속한 사용자끼리 감정을 모아 보고, 그룹장 권한과 중복 참여를 판정 사용자가 그룹을 만들거나 초대 코드로 참여할 때 저장 그룹을 삭제할 때까지 보관. 그룹을 나가도 참여 기록은 나간 시각과 함께 남음
그룹 감정 버튼 집계(그룹, 날짜, 감정 종류별 누적 횟수) 그룹 화면에 오늘 눌린 횟수 표시 그룹 멤버가 버튼을 누를 때 그룹 단위 합계만 저장. 누가 눌렀는지는 저장하지 않음 그룹을 삭제할 때까지 보관
이모지, 신고, 차단 기록(대상 감정, 기기 식별자, 이모지 종류, 신고 사유, 시각) 중복 반영 방지, 부적절한 감정 처리, 사용자가 선택한 가리기 반영 사용자가 해당 기능을 실행할 때 저장 차단은 사용자가 해제할 때까지, 신고와 이모지는 계속 보관
기기별 일자 활동 기록(기기 식별자, 활동 날짜) 날짜별, 월별 활성 사용자 수를 집계해 서비스 규모를 파악 인증된 요청이 성공하면 하루에 한 번만 기록. 어떤 요청이었는지는 저장하지 않음 집계 결과는 날짜와 플랫폼별 인원수로만 보관
무결성 증명 정보(Google Play Integrity 또는 Apple App Attest가 발급한 증명) 정품 앱과 실제 기기에서 온 요청인지 확인해 자동화된 대량 등록을 차단 기기 등록 시 앱이 전송하며 서버가 검증에만 사용하고 저장하지 않음. Android는 검증을 위해 해당 증명을 Google 서버로 전달 저장하지 않음. 증명에 쓰이는 1회용 값은 5분 안에 삭제
앱 오류와 사용 흐름 정보(오류 종류와 발생 위치, 앱 버전, 기기 모델과 운영체제 버전, 앱이 명시적으로 기록한 화면 전환과 기능 사용 이벤트) 앱 오류 원인 분석과 기능 개선 앱 실행 중 PostHog, Sentry로 전송. 화면 자동 수집, 생명주기 자동 수집, 성능 추적은 모두 꺼져 있으며 앱이 직접 정의한 이벤트만 전송. 이름, 이메일 등 식별 정보는 전송하지 않도록 설정 각 서비스의 보관 정책에 따름
서버 접속 기록(IP 주소, 요청 경로, 응답 코드, 처리 시간, 요청 추적용 임의 식별자) 장애 대응, 오류 원인 분석, 과도한 요청 차단 서버 요청 처리 중 자동 기록. 오류이거나 처리가 1초를 넘긴 요청만 기록하며 감정 내용, 위치, 기기 식별자는 기록하지 않음 모니터링 서비스(Grafana Cloud)의 보관 정책에 따름
지도 요청 정보(요청한 지도 스타일과 타일, 요청 시각, 기기와 운영체제 및 네트워크 요청에 통상 포함되는 IP 주소) 지도 화면 제공, 서비스 안정성 및 보안 유지 지도 표시 중 HTTPS를 통해 OpenFreeMap 및 그 전송 인프라로 자동 전송 운영자는 저장하지 않음. OpenFreeMap은 기본 로그에 IP 주소를 저장하지 않으며, 보안 사고 조사 시에만 최대 30일간 임시 저장할 수 있다고 고지함

2. 감정 위치를 정하는 방식과 그 한계

앱은 사용자의 실제 GPS 좌표를 운영자 서버로 보내지 않습니다. 대신 사용자가 지도에서 감정을 남길 지점을 직접 찍습니다.

  1. 앱이 위치 권한으로 받은 현재 위치를 기준으로 반경 500m 범위를 정하고, 그 안에서만 지점을 고를 수 있게 합니다. 현재 위치 자체는 기기 밖으로 나가지 않습니다.
  2. 사용자가 찍은 지점의 좌표만 서버로 전송되며, 서버는 그 값을 그대로 저장합니다.

따라서 데이터베이스에 남는 좌표는 사용자가 스스로 고른 지점이고, 운영자는 그 사용자가 실제로 어디에 있었는지 알 수 없습니다.

알아 두셔야 할 한계
저장되는 좌표는 무작위로 흩어진 값이 아니라 사용자가 의도적으로 고른 지점입니다. 자기 집이나 직장처럼 특정 장소를 반복해서 찍으면 그 지점에 기록이 쌓이고, 운영자는 기기 식별자를 저장하므로 이론적으로 같은 기기의 기록을 모아 볼 수 있습니다. 운영자는 이 목적으로 데이터를 이용하지 않으며, 응답에도 기기 식별자를 내보내지 않습니다. 알려지고 싶지 않은 장소가 있다면 그 지점을 피해서 찍으시면 됩니다. 위치 권한을 끄면 현재 위치 표시와 감정 남기기 기능이 제한됩니다.

3. 처리하지 않는 정보

현재 버전의 앱은 이름, 이메일 주소, 전화번호, 계정 또는 비밀번호, 연락처, 사진과 동영상, 건강 정보, 금융과 결제 정보, 광고 ID와 기기 고유 번호(IMEI, MAC 주소, 광고 식별자 등), 광고 정보를 수집하지 않습니다. 회원가입 기능을 제공하지 않습니다.

앱 자체는 쿠키, 웹 비콘 또는 이와 유사한 사용자 추적 장치를 설치하거나 운영하지 않습니다.

음성 녹음에 관한 안내
이전 방침은 마이크 입력의 세기만 기기 안에서 측정하고 녹음 내용을 저장하거나 전송하지 않는다고 안내했습니다. 이번 개정부터는 사용자가 감정에 녹음을 첨부하면 그 음성 파일이 운영자의 저장소에 보관됩니다. 목소리는 그 자체로 개인을 알아볼 수 있는 정보가 될 수 있으므로, 녹음은 사용자가 직접 첨부를 선택한 경우에만 전송됩니다. 숨을 불어 감정을 남기는 기능은 종전과 같이 마이크 입력의 세기만 기기 안에서 측정하며 그 과정의 소리를 저장하거나 전송하지 않습니다.

4. 개인정보의 제3자 제공과 처리 위탁

운영자는 사용자의 개인정보를 판매하지 않습니다. 서비스를 제공하기 위해 아래 외부 서비스를 이용하며, 법령상 요구되는 경우에는 적법한 절차에 따라 정보를 제공할 수 있습니다.

5. 국외 처리 가능성

위 제4조의 서비스는 대한민국 밖에 있는 서버에서 처리될 수 있습니다. 처리 항목, 목적, 기간은 제1조와 제4조에 기재된 내용과 같습니다. 사용자는 위치나 마이크 권한을 거부하거나 앱의 네트워크 사용을 중단하여 이러한 처리를 피할 수 있으나, 이 경우 감정 남기기, 녹음 첨부, 지도 표시 기능이 제한될 수 있습니다. OpenFreeMap 관련 권리는 privacy@openfreemap.org로 행사할 수 있습니다.

6. 보유 기간과 파기 방법

  • 실제 위치: 파일이나 데이터베이스에 저장하지 않고 앱 메모리에서만 처리합니다. 새 위치가 기존 값을 대체하거나 앱 프로세스가 종료되면 복구할 수 없는 방식으로 메모리에서 사라집니다.
  • 감정: 삭제하면 다른 사용자에게 보이지 않도록 즉시 가려지며, 데이터베이스에는 삭제 표시와 함께 계속 보관됩니다. 서로 다른 기기 5대 이상에게 신고된 감정은 자동으로 가려집니다.
  • 음성 녹음 파일: 연결된 감정을 삭제하거나 다른 내용으로 바꾸어도 이미 올라간 녹음 파일은 저장소에 남습니다. 감정에 연결되지 않은 채 업로드된 파일도 자동으로 지워지지 않습니다. 삭제를 원하시면 제8조의 방법으로 요청해 주십시오.
  • 그룹과 참여 기록: 그룹을 나가도 참여 기록은 나간 시각과 함께 남습니다. 그룹을 삭제하면 그룹 정보와 스탬프, 버튼 집계가 함께 가려집니다.
  • 기기 정보와 인증 토큰: 앱을 삭제해도 서버에서 자동으로 지워지지 않습니다. 삭제를 원하시면 제8조의 방법으로 요청해 주십시오.
  • 무결성 증명과 1회용 값: 증명은 저장하지 않으며, 증명에 쓰는 1회용 값은 발급 후 5분 안에 삭제합니다.
  • 외부 서비스 로그: 각 서비스의 개인정보 처리방침에 따릅니다.

7. 앱 권한

권한목적필수 여부
대략적인 위치대략적인 현재 위치를 지도에 표시하고 감정을 찍을 수 있는 범위를 정하는 데 사용선택
정확한 위치정확한 현재 위치와 정확도 범위를 지도에 표시하고 감정을 찍을 수 있는 범위를 정하는 데 사용선택
마이크숨을 부는 세기를 기기 안에서 측정하고, 사용자가 선택한 경우 감정에 첨부할 음성을 녹음해 서버 저장소로 전송선택
인터넷 및 네트워크 상태(Android)감정을 주고받고 지도 스타일과 타일을 불러오며 네트워크 오류를 처리필요

위치나 마이크 권한을 허용하지 않아도 해당 기능을 제외한 앱 기능을 이용할 수 있습니다. 권한은 기기 설정의 “앱 > Pheeeew > 권한”에서 언제든지 변경할 수 있습니다. 앱은 백그라운드 위치 권한을 요청하거나 앱이 백그라운드에 있을 때 위치를 지속적으로 수집하지 않습니다.

8. 정보주체의 권리와 행사 방법

사용자는 위치와 마이크 권한을 거부하거나 철회할 수 있고, 운영자가 보유한 개인정보의 열람, 정정, 삭제, 처리정지를 요청할 수 있습니다.

앱에는 회원가입과 로그인이 없어 운영자가 사용자를 이름이나 연락처로 확인할 수 없습니다. 따라서 삭제를 요청하시려면 앱에서 남긴 감정의 내용과 대략적인 작성 시각 등 해당 기록을 특정할 수 있는 정보를 알려 주셔야 합니다. 정보가 부족해 본인의 기록임을 확인할 수 없는 경우 요청에 응하지 못할 수 있으며, 그 사유를 안내해 드립니다.

개인정보 관련 요청은 제10조의 담당자에게 보내 주십시오. 운영자는 적용 법령에서 정한 기간 안에 답변합니다.

9. 아동의 개인정보

앱은 연령 정보를 수집하지 않으며 아동으로부터 개인정보를 고의로 수집하지 않습니다. 앱의 대상 연령층을 아동으로 설정해 배포하는 경우 운영자는 Google Play 가족 정책과 적용 법령에 필요한 추가 동의, 보호 절차를 적용하고 이 방침을 갱신합니다.

10. 안전성 확보 조치

  • 실제 위치를 서버로 보내지 않고, 사용자가 지도에서 직접 찍은 지점의 좌표만 전송합니다.
  • 인증 토큰은 해시만 저장하며 원문을 보관하지 않습니다.
  • 기기를 가리키는 값으로 순차 번호가 아닌 무작위 UUID를 사용해 다른 기기를 추측할 수 없게 합니다.
  • 감정 내용, 위치, 기기 식별자, 인증 토큰은 서버 로그에 기록하지 않습니다.
  • 녹음 파일은 공개 읽기가 차단된 저장소에 두고, 업로드와 재생에 각각 짧게 유효한 일회용 주소를 발급합니다. 주소는 데이터베이스에 저장하지 않습니다.
  • 같은 업로드 주소로 파일을 덮어쓸 수 없도록 저장소 수준에서 막고, 하나의 업로드는 하나의 감정에만 연결됩니다.
  • 앱과 서버, 외부 서비스 사이의 모든 통신에 HTTPS를 사용합니다.
  • 기기 등록 경로에 요청 수 제한을 두어 자동화된 대량 등록을 제한합니다.
  • 데이터베이스는 외부에서 직접 접근할 수 없는 망에 두고, 서버 접근은 인증된 경로로만 허용합니다.
  • 운영자는 앱과 사용하는 외부 구성요소를 주기적으로 점검하고 불필요한 권한, SDK를 추가하지 않습니다.
