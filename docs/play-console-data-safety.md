# Google Play 데이터 보안 답변 초안

> **내부 작업 문서입니다.** 이 파일은 Play Console에 제출하는 답변 자체가 아니며, 사용자에게 공개되는 데이터 보안 섹션도 아닙니다. Play Console 양식에는 실제 배포 중인 모든 앱 버전과 SDK의 데이터 처리를 반영해야 합니다. 아래는 2026-09-30 기준 개인정보 처리방침과 저장소에서 확인한 동작을 바탕으로 한 초안입니다. 제출 직전에 출시 AAB, 서버 설정, Play Console의 최신 데이터 유형 정의를 다시 확인하고 미확정 항목을 결정하세요.
>
> 공식 안내: [Google Play 데이터 보안 섹션 작성](https://support.google.com/googleplay/android-developer/answer/10787469)

## 현재 확인된 데이터 흐름

| 데이터 | 앱/서버 동작 | 보유·처리 |
| --- | --- | --- |
| 사용자가 지도에서 지정한 감정 위치 | 위도·경도를 감정 등록 시 서버로 전송. 실제 GPS 좌표를 그대로 전송하는 것은 아님 | 감정 데이터와 함께 데이터베이스에 계속 보관. 앱 내 삭제나 신고에 따른 숨김은 물리적 파기가 아님 |
| 현재 기기 위치 | 위치 권한을 허용하면 지도 표시와 선택 가능 범위(현재 위치 주변 500m)에 사용 | 기기 안에서만 사용하고 서버로 전송하지 않음 |
| 감정 상태, 메모, 시각 | 사용자가 감정을 등록할 때 서버에 전송 | 감정 데이터베이스에 계속 보관. 메모와 녹음은 함께 등록할 수 없음 |
| 음성 녹음 | 사용자가 녹음을 선택한 경우 앱에서 녹음하고, 일회용 업로드 주소로 Amazon S3에 직접 전송. 감정 상세에서 재생 | 업로드된 오디오 객체는 감정 삭제·변경과 무관하게 계속 보관하며 현재 별도 파기하지 않음 |
| 기기 식별자 | 서버가 생성한 무작위 UUID로 같은 설치의 요청·감정 등을 구분. 광고 ID, IMEI, MAC 주소는 사용하지 않음 | 서버에 보관. 앱 삭제만으로 서버 기록은 자동 삭제되지 않음 |
| 그룹 및 참여 정보, 이모지·신고·차단 기록 | 그룹 기능 및 사용자가 선택한 기능을 제공하기 위해 서버로 전송 | 개인정보 처리방침에 정한 기간·방식으로 보관. 감정 데이터 삭제와 별도 확인 필요 |
| 앱 사용 이벤트와 오류 정보 | 앱이 명시적으로 정의한 이벤트만 PostHog로 전송. 오류 정보는 Sentry로 전송. 자동 화면·생명주기 수집과 성능 추적은 꺼져 있다고 개인정보 처리방침에 기재 | 각 서비스의 보관 정책에 따름. 실제 Android 출시 설정과 SDK 동작 확인 필요 |
| 서버 오류·지연 요청 로그 | 오류 또는 1초 초과 요청의 IP, 경로, 응답 코드, 처리 시간 등을 Grafana Cloud로 전송 | Grafana Cloud 보관 정책에 따름 |
| 지도 요청 정보 | 지도 스타일·타일 요청이 OpenFreeMap 및 전송 인프라로 전달되며 네트워크 요청에 IP가 포함될 수 있음 | 외부 제공자의 처리·보관 정책 확인 필요 |
| 무결성 증명 | Android Play Integrity 증명을 서버가 검증 목적으로 Google에 전달 | 증명 자체는 서버에 저장하지 않음. 1회용 값은 5분 안에 삭제 |

## Play Console 답변 초안

**아래 표의 “확인 필요”는 최종 답변이 아닙니다.** Google Play의 데이터 유형 정의와 현재 출시 트랙에서 실제로 수집하는 데이터에 맞춰 제출 전에 확정해야 합니다.

| Play 데이터 유형 | 수집 | 공유 | 목적·선택 여부 | 확인 사항 |
| --- | --- | --- | --- | --- |
| 위치 → 정확한 위치 | **확인 필요, 보수적으로 예 검토** | **확인 필요** | 앱 기능. 감정 등록 시 사용자가 직접 지정한 좌표는 제출되고 저장됨. 위치 권한으로 읽은 현재 GPS 좌표는 기기 밖으로 보내지 않음 | 예전의 “300m 흐림 위치” 설명은 현재와 다름. 사용자가 고른 정확한 위·경도가 Play의 정확한 위치에 해당하는지 최신 정의로 판단. 공개 지도에 표시되는 점의 공유 답변도 확인 |
| 앱 활동 → 기타 사용자 제작 콘텐츠 | **예** | **확인 필요** | 앱 기능. 감정 메모 등 사용자가 작성한 콘텐츠. 메모 입력은 선택 | 콘텐츠가 다른 사용자에게 보이는 방식과 Play의 사용자 주도 공유 예외 적용 여부 확인 |
| 오디오 파일 → 음성 또는 사운드 녹음 | **예** | **확인 필요** | 앱 기능. 사용자가 선택해 녹음·업로드하므로 선택 사항 | S3는 개발자 지시에 따라 저장만 하는 서비스 제공자인지 확인. 오디오가 다른 사용자에게 재생되는 흐름에 대한 공유 답변도 양식 정의에 따라 판단 |
| 기기 또는 기타 ID | **예** | **아니오 초안** | 앱 기능, 기기별 중복 방지 및 요청 연결. 기기 등록에 필요 | 서버 발급 UUID도 설치 단위로 요청을 연결하므로 수집에 포함하는 보수적 초안. 서비스 제공자 외 제3자 전달 여부 확인 |
| 앱 정보 및 성능 → 진단 | **예 초안** | **아니오 초안** | 앱 오류 분석 및 안정성 개선. 앱이 동작에 따라 자동 수집하는 데이터일 수 있음 | Sentry, Grafana Cloud의 실제 설정·처리 목적을 확인. 개발자를 대신해 처리하는 서비스 제공자 예외가 성립하는지 확인 |
| 앱 활동 → 기타 작업 또는 사용 이벤트 | **예 초안** | **아니오 초안** | PostHog에 앱이 명시적으로 기록한 기능 사용 이벤트 전송 | 실제 이벤트 이름·속성, 기기 식별자 포함 여부, SDK 자동 수집 여부를 Android 릴리스 설정으로 확인 |
| 네트워크 요청의 IP 주소 | **확인 필요** | **확인 필요** | 서비스 제공, 지도·오디오 요청, 장애 대응 및 보안 | IP가 각 서비스에서 어떻게 사용되는지 확인해 해당 데이터 유형과 제3자 공유 여부를 최신 Play 정의에 따라 판단 |

Google 안내에서 “수집”은 앱 또는 SDK가 데이터를 기기 밖으로 전송하는 경우를 포함합니다. 오디오 파일은 사용자가 선택해 업로드하더라도 S3에 저장되므로 수집 초안은 **예**이며 일시 처리로 볼 수 없습니다. Google은 개발자를 대신해 지시에 따라 처리하는 서비스 제공자에게 전송하는 경우를 공유에서 제외할 수 있다고 설명하지만, 실제 처리 관계와 앱 안에서 다른 이용자에게 공개되는 흐름은 따로 확인해야 합니다.

## 삭제 요청 및 보안 답변

| Play Console 질문 | 현재 확인 내용 | 제출 전 조치 |
| --- | --- | --- |
| 전송 중 암호화 | 앱·서버 및 외부 서비스 요청은 HTTPS로 처리한다고 개인정보 처리방침에 기재 | 배포 AAB와 전체 SDK·외부 요청에서 확인 |
| 사용자가 데이터 삭제를 요청할 수 있는가 | 개인정보 처리방침은 이메일 문의 경로를 안내하지만, 앱 내 감정 삭제는 숨김이며 감정·오디오 객체는 서버에서 물리적으로 파기하지 않음 | 요청을 실제로 접수·검토·처리하는 절차와 법적 예외를 운영자가 확정하기 전에는 “삭제 가능”으로 단정하지 말 것. Play 양식의 삭제 요청 경로에 어떤 주소를 넣을지도 확인 |
| 데이터 수집이 필수인가 | 오디오 녹음과 메모는 사용자가 선택. 감정 등록·기기 식별자 등은 기능별로 다름 | Play가 말하는 필수/선택 기준에 따라 각 데이터 유형을 따로 판정 |

현재 앱의 숨김 기능과 정보주체의 법적 삭제 요청은 같은 기능이 아닙니다. 영구 보관 사실과 삭제 요청 처리 방식이 개인정보 처리방침, 실제 운영 절차, Play Console 답변에서 서로 모순되지 않도록 확인하세요.

## Play Console 제출 전 체크리스트

- [ ] Play Console에 현재 배포 중인 모든 Android 버전의 동작을 반영했는가
- [ ] 출시 AAB의 권한, Android SDK, PostHog·Sentry 설정과 자동 수집 동작을 확인했는가
- [ ] 정확한 현재 위치가 서버로 전송되지 않는 것과 사용자가 지정한 감정 좌표가 저장되는 것을 구분했는가
- [ ] 오디오 녹음 업로드와 S3 보관을 오디오 파일 데이터 유형에 반영했는가
- [ ] 오디오·감정 메모·지도 좌표가 다른 이용자에게 표시되는 흐름과 공유 답변을 확인했는가
- [ ] AWS, PostHog, Sentry, Grafana Cloud, OpenFreeMap이 서비스 제공자로서 처리하는 범위를 확인했는가
- [ ] 서버 발급 UUID와 IP 주소를 해당 데이터 유형에 반영했는가
- [ ] 데이터 삭제 요청의 실제 접수·처리 절차와 제출할 URL을 확정했는가
- [ ] 개인정보 처리방침 및 App Store Connect의 App Privacy 답변도 같은 출시 동작과 일치하는가

## App Store도 별도 확인

App Store Connect의 App Privacy는 Google Play와 데이터 유형·질문 체계가 다릅니다. 최소한 위치 좌표, 감정 메모, 음성 녹음, 기기 식별자, 진단 정보, 외부 서비스 및 보유·삭제 방식을 현재 출시 앱 기준으로 다시 검토하세요. Android 데이터 보안 표를 그대로 복사하지 마세요.
