## Intro

좋은 기분과 행복한 순간은 그 자체로 즐기면서 주변 사람들과 편하게 공유할 수 있어요.<br/>
그런데 힘든 순간은 많이 달라요.

등교/출근하자마자 하교/퇴근하고 싶고, 별일 아닌 한 마디에 화가 나고 그냥 모든 게 다 귀찮은 날. <br/>
누군가에게 털어놓고 싶지만 사소한 일로 상대에게 부담을 줄까봐 망설이게 되는 그런 순간들..

누구나 힘든 날이 있지만, 모든 감정에 조언이나 해결책이 필요한 것은 아니에요.<br/>
사용자가 부담 없이 감정을 남기고 서로의 하소연에 공감하며 힘든 순간을 조금은 유쾌하게 넘길 수 있는 공간. "히유"에서 함께해요!
