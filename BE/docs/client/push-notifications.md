# 푸시 알림 발송과 표시 계약

관련 이슈: [#929](https://github.com/woowacourse-teams/2026-pheeeew/issues/929), [#933](https://github.com/woowacourse-teams/2026-pheeeew/issues/933), [#934](https://github.com/woowacourse-teams/2026-pheeeew/issues/934), [#935](https://github.com/woowacourse-teams/2026-pheeeew/issues/935)

## 역할 구분

| 항목 | 백엔드 | 앱 |
| --- | --- | --- |
| 보낼지 정하기 | 발송 조건, 그 시점의 수신 설정, 푸시 등록 값을 확인해서 보냅니다 | 관여하지 않습니다 |
| 앱 사용 여부, 보고 있는 화면 | 추적하지 않습니다 | 앱이 판단합니다 |
| 받은 알림을 보여 주는 방식 | 정하지 않습니다 | 아래 표시 정책을 따릅니다 |

서버는 앱을 사용 중인 기기에도 똑같이 보냅니다. 포그라운드에서 받은 메시지를 어떻게 처리할지는 앱이 정합니다.

## 알림 종류

| 알림 | 수신 설정 | 보내는 조건 |
| --- | --- | --- |
| 컬렉션 발급 가능 | `collectionClaimableEnabled` | 그날 처음 발급 가능한 것을 확인하고 1시간 뒤에도 받지 않은 카드가 있을 때. 기기마다 하루 한 번 |
| 컬렉션 리마인더 | `collectionClaimableEnabled` | 매일 23:00 KST 에 받지 않은 카드가 있을 때 |
| 순위 변동 | `rankChangedEnabled` | 1시간마다 개인 일별 프레스 순위를 비교해, 이전이나 현재 순위가 5위 안이고 바뀌었을 때. 오늘 프레스가 0건이면 보내지 않음 |

- 발급 가능은 오늘 어떤 감정이든 스탬프 1개 이상, 프레스 100회 이상이고 그 감정의 카드를 아직 받지 않은 상태입니다.
- 카드를 이미 받은 감정은 컬렉션 알림 대상에서 뺍니다. 받을 수 있는 카드를 모두 받았으면 보내지 않습니다.
- 순위 변동 알림은 #935 에서 구현합니다. data 키는 그때 이 문서에 추가합니다.

## 메시지 형식

FCM 메시지는 `notification`(제목, 본문)과 `data` 를 함께 담습니다. `data` 의 값은 모두 문자열입니다.

| 알림 | `data.type` | `data.date` |
| --- | --- | --- |
| 컬렉션 발급 가능 | `COLLECTION_CLAIMABLE` | 카드를 받을 수 있는 날짜(KST, `yyyy-MM-dd`) |
| 컬렉션 리마인더 | `COLLECTION_CLAIM_REMINDER` | 카드를 받을 수 있는 날짜(KST, `yyyy-MM-dd`) |

- 컬렉션 알림에는 카드 식별자가 없습니다. 아직 받지 않은 카드라서 그렇습니다. 앱은 `type` 으로 컬렉션 화면을 정하고 오늘 진행도를 다시 조회합니다.
- `date` 가 오늘이 아니면 이미 지난 알림입니다. 카드는 그날 안에만 받을 수 있습니다.

## 표시 정책

| 앱 상태 | 표시 |
| --- | --- |
| 사용하지 않을 때 | 일반 푸시 알림을 표시합니다 |
| 사용 중일 때 | 시스템 배너와 소리를 생략하고 앱 안에서 짧게 안내합니다 |
| 해당 컬렉션, 순위 화면을 보고 있을 때 | 안내 없이 화면 데이터만 갱신합니다 |

## 푸시 등록 값과 수신 설정

- 앱이 활성화될 때마다(콜드 스타트, 포그라운드 복귀) OS 알림 권한이 허용이면 현재 값을 `PUT /api/v3/devices/me/push-token` 으로 보내고, 거부면 `DELETE /api/v3/devices/me/push-token` 을 호출합니다. SDK 가 새 값을 알려 줄 때도 보냅니다.
- 푸시 등록 값을 보내거나 지워도 수신 설정은 바뀌지 않습니다.
- 수신 설정은 `GET`, `PUT /api/v3/devices/me/notification-settings` 로 기기별로 조회하고 바꿉니다. 바꾼 적이 없으면 두 값 모두 true 입니다.
- 수신 설정 API 는 위 두 값만 다룹니다. 앱 사용 여부나 표시 방식은 서버에 보내지 않습니다.
