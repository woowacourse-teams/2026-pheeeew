# 감정 상태 코드와 앱 이미지 연결 초안

이 표는 백엔드가 클라이언트에 제안하는 초기 연결 계약이에요. 클라이언트와 원본 이미지 파일을 확인한 뒤 파일명까지 합의해야 해요.

| 감정 상태 | API·DB 코드 | 앱 이미지 자산 이름 제안 |
| --- | --- | --- |
| 답답 | `FRUSTRATED` | `FRUSTRATED` |
| 짜증 | `IRRITATED` | `IRRITATED` |
| 지침 | `EXHAUSTED` | `EXHAUSTED` |
| 좌절 | `DISCOURAGED` | `DISCOURAGED` |
| 분노 | `ANGRY` | `ANGRY` |

앱은 원본 이미지를 빌드할 때 포함하고, 서버가 반환하는 상태 코드로 표시할 이미지를 선택해요. 서버는 이미지 파일이나 다운로드 주소를 제공하지 않아요. 파일 확장자와 실제 원본 파일명은 이미지 전달 시 함께 확정해요.
