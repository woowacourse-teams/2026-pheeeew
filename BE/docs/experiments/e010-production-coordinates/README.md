# E010 실제 서버 생성기·PostGIS 좌표 비교

## 실행 전 고정 조건

질문은 실제 서버의 균등 원 구현이 선택한 E009의 이중 원 분포를 재현하고 기존 사각형 윤곽을 바꾸는지예요. 가설은 새 두 경로가 E009의 평면 좌표와 0.0001m 이내에서 일치하며, 클라이언트까지 바꾼 경우 단일 장소의 외곽이 완만해진다는 것이에요. 시각 선호의 승자를 자동 판정하지 않아요.

E007의 D행에서 stationary-5000 전체 5,000개, hotspots-4500 전체 4,500개, uniform-45000의 각 seed에서 index < 900인 4,500개를 가져와요. 장면 이름은 마지막만 uniform-4500으로 표시해요. 다섯 seed 2026090701~2026090705와 동일 이벤트의 합성 실제 위치를 세 경로가 공유해요. 총 14,000개 이벤트이고 결과는 실행당 42,000행이에요. 고밀도 45,000개 장면은 이번 실행에 포함하지 않아요.

| 그림 열 | 클라이언트 모의 | 서버 처리 |
| --- | --- | --- |
| 왼쪽 기존 사각형 | EPSG:5179 300m 격자 중심 | 이전 구현의 축별 [-150,150) 균등 식을 재현하고 실제 Repository 공간 변환을 사용해요 |
| 가운데 서버만 원 | 합성 실제 위치 전송을 모의 | 현재 PostgisSighLocationGenerator를 호출해요. 제품의 실제 위치 전송을 허용한다는 뜻은 아니에요 |
| 오른쪽 클라이언트+서버 원 | 실제 위치 주변 300m 균등 원 좌표 전송을 모의 | 동일한 현재 PostgisSighLocationGenerator를 호출해요 |

지역 평면 원점은 EPSG:5179 (953850,1951950)으로 고정해요. 300m 셀 중심에 맞춘 원점이므로 E007의 로컬 격자와 기존 제품 격자 규칙이 일치해요. 좌표를 실제 PostGIS에서 WGS84로 변환해 생성기에 전달하고, 반환 WGS84를 다시 EPSG:5179로 바꾸어 로컬 산점도를 그려요. 실제 사용자 위치·운영 DB는 사용하지 않아요.

서버 난수 seed는 E009와 같은 SHA-256("e009|server|scene|seed|index") 첫 8바이트 big-endian long이에요. 클라이언트는 "e009|client|scene|seed|index"를 써요. 서버 생성기의 package-private 테스트 생성자에 SplittableRandom을 주입하고, 클라이언트는 별도 난수열로 원 이동을 모의해요. 세 경로는 이벤트별 서버 첫 두 난수를 공유해요. 배포용 공개 생성자는 SecureRandom을 사용하며 바꾸지 않아요. 이는 실제 생성기·공간 변환의 검증이지 배포 난수원 품질·성능 벤치마크가 아니에요.

## 그림 계약

동일 장면 세 열 산점도 PNG 3장을 만들어요. 각 패널 1000×1000px, 전체 3264×1240px, 모든 장면 x/y ±1200m 동일 축척, 기존 E001 금색 6px 별·어두운 배경, 나이 0h·alpha 1로 고정해요. 금색 하나를 사용하고 직접 제목과 열 순서로 구분해요. 표본을 숨기거나 모델마다 자동 확대하지 않아요. 질문이 위치 모양이므로 세 그림 모두 산점도예요. 정적 PNG를 저장소·옵시디언·대화에서 제공해요. 지도 타일·줌·앱 렌더러는 실행하지 않아요.

## 검증과 재현

PostgreSQL 17·PostGIS 3.5 Testcontainers와 실제 Repository·생성기를 사용해요. 두 번 실행한 CSV·지표·PNG 해시가 같아야 해요. 격자 공식, 기존 사각형 범위, 각 원의 300m와 합산 600m 평면 범위, E009의 같은 이벤트 좌표와의 오차, 표시 잘림 0을 검사해요. 소스·입력 해시는 실행 전에 출력 폴더에 기록하고 끝에 같은 값인지 확인해요. 좌표 생성 후 저장/조회 API를 호출하는 실험은 아니며, 저장·동시 멱등성은 직전 81개 테스트 검증을 근거로 구분해요.

```bash
./gradlew e010ProductionCoordinates --no-daemon
```

기본 결과는 `build/reports/experiments/e010-production-coordinates/`예요. 기존 출력 디렉터리가 있으면 덮어쓰지 않고 실패해요. 새 위치가 필요하면 `-Pe010Output=/absolute/new/output/path`로 아직 존재하지 않는 디렉터리를 지정해요. 일반 `test`에서는 e010 tag를 제외해 일상 테스트가 대량 좌표를 생성하지 않아요.

결과를 재생성해도 실제 앱의 모양, 구형 앱 전환 완료, 배포 승인 또는 프라이버시 보장을 증명하지 않아요. 300m·600m는 EPSG:5179 평면 기준이며 실제 지표면 거리에는 투영 오차가 있어요.
