> 현재 상태: 사용자 승인으로 모델을 공개했어요. [모델 공개 기록](../MODEL-DISCLOSURE.md)에 따라 독립 평가는 미완료로 종료·보존하며, 아래 대기·key 미열람 설명은 공개 전 이력이에요. 응답 네 행은 수정하거나 복제하지 않았어요.

> 실행 담당자용이에요. 다른 평가자의 응답에 영향을 주지 않도록 공개 평가 package에는 넣지 않아요. 전체 응답이 모이기 전에는 모델별 집계·key 확인·최종 판정을 하지 않아요.

> 후속 확인: 사용자가 아래 네 응답과 같은 결과를 팀의 다수결 합의로 전달했고, ‘팀 합의에 따른 선택’으로 기록하도록 요청했어요. 기존 네 행은 수집 당시 원본이며 독립성이 확인된 평가로 간주하지 않아요. 개인별 나머지 16행이나 득표수는 제공되지 않았어요.

## 2026-09-07 — 팀 합의로 기록 방식 구분

사용자는 다른 네 명도 참여해 다수결로 합의했다고 설명했고, 독립 평가와 구분해 “팀 합의에 따른 선택으로 기록해줘”라고 요청했어요. 팀의 최종 답은 그림 순서대로 `left/left/neither`, `right/right/neither`, `left/left/right`, `right/right/left`예요. 질문 순서는 shape/natural/hotspot이에요.

합의 결과는 확인했지만 개인별 응답·득표수·전원 일치는 확인하지 않았어요. 기존 CSV 네 행은 변경하지 않고 나머지 평가자의 행을 만들어 넣지 않아요. 앞선 ‘1/5명 완료’는 수집 당시의 분류 이력이며, 현재는 다섯 명의 독립 평가가 검증됐다는 근거로 사용하지 않아요.

팀 합의 기록은 완료했으며 프로토콜 추천 `pending-review`와 구분해요. key 확인·모델별 판정·제품 채택은 하지 않았어요. 옵시디언 결정 기록 ‘2026-09-07 E001 시각 비교를 팀 합의에 따른 선택으로 기록’에 출처·선택표·범위를 남겼어요.
