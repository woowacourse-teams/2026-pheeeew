# 팀 합의 결과의 모델 공개

2026-09-07 사용자가 독립 평가를 미완료로 보존한 채 팀 합의에 따른 선택을 확인하도록 모델 공개를 승인했어요. 아래 내용은 그 승인에 따른 사후 공개예요. 기존 사전등록 기준을 소급 수정하거나 독립 평가 통과로 바꾸지 않아요.

## 확인 결과

**팀이 모양과 자연스러움에서 선택한 쪽은 네 그림 모두 D였어요.** D는 `d-s120-r300`, 즉 σ=120m·반경 300m의 tapered Gaussian이에요. A는 기존 `a-square-300` 균등 정사각형이에요.

| 그림 | 공개 pair ID | 왼쪽 | 오른쪽 | 팀의 모양·자연스러움 선택 | 팀의 부적절한 과밀 판단 |
| --- | --- | --- | --- | --- | --- |
| 1 · 3×3 중심당 500개 | `047f13aad87b1321` | D | A | 왼쪽 → D | 없음 |
| 2 · 단일 중심 500개 | `0c695574696c5768` | A | D | 오른쪽 → D | 없음 |
| 3 · 3×3 중심당 5,000개 | `656ab089a201b687` | D | A | 왼쪽 → D | 오른쪽 → A |
| 4 · 단일 중심 5,000개 | `71d7e3db3e9dee55` | A | D | 오른쪽 → D | 왼쪽 → A |

이는 사용자가 전달한 다수결 합의의 해석이에요. 5명 전원 일치나 개인별 득표수, 일반 사용자 선호를 뜻하지 않아요. ‘네 그림 모두 D’는 조건 네 개의 선택이고 ‘다섯 명 모두 D’라는 주장이 아니에요.

## D가 뜻하는 방식

입력은 기존과 같은 300m 격자 중심이에요. 그 중심 주변에 별을 더 많이 생성하고 바깥으로 갈수록 확률을 줄이되, 반경 300m에 다가갈수록 추가로 부드럽게 감쇠해요. 최대 지지영역은 지름 600m이고 중심으로부터 `r<300m`를 지켜요.

σ=120m는 경계 감쇠를 적용하기 전 가우시안 커널의 파라미터이며 최종 좌표의 표준편차나 최대 이동 거리가 아니에요. 이 감쇠는 **위치 생성 확률**에 적용하며 별 밝기 감쇠가 아니에요. 시간 감쇠·줌별 크기·기존 별 재배치는 여전히 별도 범위예요.

E는 D에 전역 다중 스케일 강도장을 결합한 더 복잡한 후보였고, 이번 수치 기준을 통과하지 못해 이 네 그림에 포함되지 않았어요. 따라서 팀이 D와 E를 시각적으로 비교해 D를 골랐다는 해석은 하지 않아요. 위치 분포를 단순화하는 적용 후보는 D로 좁혀졌지만 제품 채택·ADR·실제 저장 로직 전환은 아직 하지 않았어요.

## 정답표 검증

보존한 `coordinator-only/raw/blind/manifest.json`의 원본 파일 checksum 7개를 재계산했고, key의 공개 pair ID 네 개가 배포된 목록과 일치하는지 확인했어요. 원래 nonce로 HMAC pair ID와 좌우 배치를 재계산해 네 쌍 모두 검증했어요. 새 배치를 생성하지 않았고 nonce 자체는 공개 문서에 싣지 않았어요.

키의 A/D 표시는 root manifest의 A `a-square-300`, 선택 D `d-s120-r300`와 연결해요. [기존 수집 CSV](coordinator-only/collected-responses.csv)는 네 행 그대로 보존했고 다른 평가자 응답을 만들지 않았어요. 원본·성능·그림을 다시 생성하지 않았어요.

## 독립 평가 종료와 근거의 경계

| 구분 | 현재 기록 |
| --- | --- |
| 분포·성능 | 기존 검증 결과를 유지해요. |
| 팀 합의 | 네 조건에서 D를 선호한 것으로 확인했어요. |
| 독립 블라인드 평가 | **미완료로 종료·보존**해요. 독립성·20행·득표 조건을 검증하지 않았어요. |
| 종료 시 프로토콜 추천 | `pending-review`를 이력으로 남겨요. `recommend-d`나 합격을 산출하지 않았어요. |
| 공개 후 batch | 모델이 공개돼 **독립 블라인드 평가에 재사용하지 않아요.** |

원본 sidecar의 `status=valid`와 `reviewStatus=awaiting-five-reviewers`는 생성 당시 metadata이며, 현재 블라인드 유효성이나 평가 대기 상태를 의미하지 않아요. 원본 checksum 보존을 위해 수정하지 않고 이 문서로 공개·종료를 명시해요. 공개 전의 안내·응답 기록도 이력으로 남겨요.

등록된 노출 후 재생성 절차 대신, 사용자가 승인한 ‘미완료 보존 후 공개’를 이번 작업에 적용했어요. 자동 무효화·새 nonce 생성 task를 실행하지 않았어요. 향후 독립 평가가 필요하면 이 batch에 응답을 더해 합격시키지 않고 별도 승인된 재평가 절차가 필요해요.

## 다음 작업의 경계

모델 공개와 근거 정리는 끝났어요. 기록은 미커밋이에요. 이후 커밋은 명시적 승인을 받아요. 제품 적용은 D를 기준으로 채택 근거·현행 ADR과의 차이·저장 경로 검증 범위를 먼저 정리한 뒤 별도 단위로 진행해요. 현재 제품 코드·API·DB·ADR은 변경하지 않았어요.
