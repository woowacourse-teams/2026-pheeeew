# E007 격자 없는 클라이언트 위치 탐색 비교

2026-09-07 사용자 요청으로 D / 클라이언트 가우시안 / 클라이언트 2차원 라플라스를 **합성 데이터에서만** 비교해요. 제품 API·클라이언트·ADR·저장 로직은 바꾸지 않아요. 기존 미커밋 E006을 보존하고 새 실험만 추가해요. 비블라인드 탐색이며 모델 채택이나 개인정보 보호 인증이 아니에요.

## 실행 전 고정한 모델과 거리 기준

| 모델 | 합성 실제 위치 x에서 표시 위치 z 생성 |
| --- | --- |
| D | 각 축을 floor((x+150)/300)*300으로 변환한 중심 + 기존 E001 σ120m tapered Gaussian이에요. |
| G | 격자 없이 x + isotropic Gaussian이에요. 서버 추가 잡음은 없어요. |
| L | 격자 없이 x + planar Laplace예요. 서버 추가 잡음은 없어요. |

모든 좌표는 m 단위 로컬 평면이에요. 격자 중심을 (0,0)으로 옮긴 좌표계이므로 D의 격자 식은 기존 floor(value/300)*300+150과 평행이동 관계예요. 위경도 변환·기기 구현은 이번에 검증하지 않아요.

**균등한 셀 내부 실제 위치에 대한 기대 제곱 거리 오차**를 맞춰요. D kernel의 m2=E[r²]를 기존 taper와 σ120으로 Simpson 30,000구간 적분하고 target=m2+15,000m²로 정해요. 15,000은 2×300²/12의 격자 양자화 오차예요. G의 σ=√(target/2), L의 b=√(target/6)로 고정해요. L은 theta~U[0,2π), r=-b(log(1-U1)+log(1-U2))로 뽑으며 면적 밀도는 exp(-r/b)/(2πb²), 반경은 Gamma(shape=2,scale=b)예요. 축별 독립 Laplace가 아니에요.

이 통제는 **균등 셀 내부 위치 기준 RMS**를 맞추는 것이고, p95·최대 거리·프라이버시 수준을 맞추는 것은 아니에요. 단일 지점과 hotspot에서 D의 실제 오차는 셀 내 위치에 따라 달라져요. 모델별·장면별 실측 RMS/p50/p95/p99/max/300m 초과율을 모두 공개해요. G/L을 300m에서 자르거나 경계로 밀지 않아요.

## 합성 장면과 그림 계약

- 단일 위치 (120,-90) 5,000개, 균등 [-450,450]² 45,000개, 불규칙 hotspot 4,500·45,000개를 사용해요. hotspot은 (-330,-210),(-180,280),(80,-80),(340,190),(260,-320), 가중치 (0.30,0.20,0.25,0.15,0.10), 각각 σ55m isotropic Gaussian이에요. 지도·사람의 실제 좌표가 아니에요.
- seed 2026090701~2026090705에 표본을 1/5씩 나눠요. 같은 장면의 입력 좌표는 세 모델이 공유해요. 합계 298,500개 표시 좌표/실행이에요. 입력·모델별 난수열은 SHA-256 문자열 ID에서 얻은 long seed로 분리해요. SplittableRandom은 재현 실험용이며 배포용 보안 난수 생성기가 아니에요.
- 산점도의 질문은 같은 실제 위치 분포에서 격자 제거가 반복과 외곽에 미치는 영향이에요. 예상은 반복 감소이고 자연스러움 선호는 미정이에요. Java2D 정적 PNG, 3열 D/G/L, 동일 금색 6px sprite·어두운 기존 앱 배경·같은 x/y 축척을 사용해요. panel 1000px, 전체 3264×1240px예요. 전체 네 장면·세 모델의 최대 |좌표|에 20m 여백을 더해 300m 단위로 올림한 공통 범위(최소 ±900m)를 사용해요. 이는 실행 전 고정한 자동 범위 규칙이며 꼬리 표본을 숨기지 않아요. 모든 그림이 같은 범위를 사용해요.

## 반복 관측 진단 계약

같은 사람·장소의 표시 좌표를 공격자가 연결할 수 있다고 가정해요. (120,-90)와 (0,0) 두 고정 위치에서 모델별 500개 독립 trajectory를 만들고 각각 1,000번 생성해요. 다섯 seed에 100개 trajectory씩 배분해요. n=1,5,10,30,100,300,1000 prefix 평균을 위치 추정값으로 삼아요. 평균 좌표·실제 위치와의 오차 원본, 500개 반복의 RMS/p50/p95/25m 이내 비율을 기록해요.

두 anchor를 별도 패널로 그려요. x는 누적 공개 횟수(log10), y는 평균 추정의 RMS 오차(m), 0 시작 선형 축이에요. D/G/L은 직접 범례와 선·marker로 구분해요. 평균 공격은 하나의 공격 예시일 뿐이고 최적 공격·재식별 확률·보장된 보호 반경이 아니에요. D의 양자화 잔차는 anchor별 150m/0m라서 D를 항상 안전하다고 결론내리지 않아요. G/L의 단일 공개 RMS가 같으면 평균 공격 RMS도 이론적으로 둘 다 √(target/n)이에요. D는 √(격자 잔차²+m2/n)이에요.

기본 연속 L은 epsilon=1/b인 geo-indistinguishability 모델이지만 이 코드의 유한 정밀도·난수·반복 공개에 대한 형식 보장은 검증하지 않아요. 반복 공개 예산·재사용 정책·연결 가능성은 별도 설계 대상이에요. 샘플 그림을 보고 개인정보 정책을 바꾸지 않아요.
