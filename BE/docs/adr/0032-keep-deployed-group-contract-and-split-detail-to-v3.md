# ADR-0032: 배포된 그룹 계약을 그대로 두고 새 상세 조회를 v3 로 분리한다

## Status

Accepted (2026-10-07)

## Context

- ADR-0031 로 그룹 프레스의 원천을 개인 프레스로 바꾸면서 `POST`, `GET /api/v2/groups/{groupId}/presses` 를 제거하고 상세 응답에서 `todayPresses`, `weeklyPresses`, `weeklyPressRank` 를 없앴어요.
- **배포된 앱이 그것을 씁니다.** iOS 와 Android 는 동시에 업데이트되지 않고 심사와 점진 배포 기간이 있어요. 그 기간에 운영 환경에 배포하면 기존 사용자가 그룹 안에서 감정 프레스를 쓸 수 없어요.
- 응답에서 필드를 지우는 것이 엔드포인트 제거보다 먼저 드러나요. 상세 화면 진입 자체가 실패해요.
- **클라이언트가 모르는 키를 어떻게 다루는지 서버에서 알 수 없어요.** 모르는 키에 예외를 던지는 구현이면 필드를 더하는 것만으로도 깨져요.
- `#655`, `#658` 은 `origin/develop` 과 `origin/main` 에 아직 없어요. 배포된 계약은 `origin/develop` 이에요.
- 요청에 앱 버전이 실려 오지 않고 `app_version` 테이블에 쓰기 경로가 없어서, 전환 종료를 코드로 판정할 수단이 없어요.
- [이슈 #661](https://github.com/woowacourse-teams/2026-pheeeew/issues/661)이 복구를 요구해요.

## Decision

**배포된 계약을 바이트 단위로 그대로 복원하고, 새 계약을 `GET /api/v3/groups/{groupId}` 로 분리해요.** `GET /api/v2/groups/{groupId}` 는 멤버 전용 12 필드로 돌아가고 전환이 끝나면 통째로 지워요.
**두 원천을 합산하지 않아요.** v2 의 프레스는 `group_daily_presses`, v3 의 감정 프레스는 개인 프레스 합산만 봐요. 각 필드가 자기 원천만 봐요.
ADR-0030 의 결정(가입 여부 무관 조회, `GroupViewerRole`, 초대 코드 전체 노출)은 유효하고 **적용 지점이 v3 로 옮겨가요.**

## Alternatives

- 기존 응답에 필드만 더하기 — 모르는 키를 거부하는 클라이언트를 깨뜨릴 수 있고, 그 위험을 서버에서 확인할 수 없어요.
- 두 원천을 합산해 한 숫자로 주기 — 이중 계산을 따지는 추론이 들어가고 이전 주 판정과 동점 정렬이 함께 복잡해져요.
- `GET /api/v2/groups/{groupId}/overview` 처럼 하위 경로를 덧붙이기 — 같은 작업량으로 계약만 흐려요. 호환 불가 변경은 버전으로 드러나야 해요.
- 최소 지원 버전을 올려 강제 업데이트 — 심사와 배포 기간의 공백을 없애지 못해요.

## Consequences

- (+) 배포된 앱이 보는 응답이 `origin/develop` 과 **같은 필드, 같은 순서, 같은 타입, 같은 원천**이에요. 추측이 섞이지 않아요.
- (+) 모르는 키나 `NONE` 역할이 배포된 앱에 닿을 경로가 없어요. 그 앱은 v3 를 호출하지 않아요.
- (+) 전환이 끝나면 v2 상세와 그 DTO 를 **파일째 지우면** 끝나요. 필드를 골라낼 일이 없어요.
- (-) **`group_daily_presses` 의 경합이 돌아와요.** 한 그룹의 모두가 행 하나를 다투는 구조이고 측정된 천장이 그대로예요. 전환 기간 동안 피할 수 없어요.
- (-) 프레스 쓰기 경로가 둘이에요. 구버전은 그룹에 직접, 신버전은 개인 프레스로 써요.
- (-) **같은 그룹의 프레스 숫자가 두 개 생겨요.** v2 의 `weeklyPressRank` 와 v3 의 `weeklyEmotionPressRank` 는 원천이 달라 값이 달라요. 이름으로 구분하지만 혼동의 여지가 남아요.
- (-) `/api/v3` 에 상세 하나만 있어요. 나머지 그룹 엔드포인트 여덟 개는 `/api/v2` 에 남아요.
- (=) **전환 종료를 코드로 강제할 수 없어요.** OpenAPI `deprecated` 표기와 이 기록이 전부예요. 누군가 의식적으로 지워야 해요.
- (=) 복구한 쓰기 경로의 상한 자르기, 잠금 순서, 데드락 방지에 자동 검증이 없어요. 복구 코드가 제거 직전 커밋과 바이트 단위로 같다는 사실에 의존해요.
- (=) ADR-0031 의 Decision 중 "엔드포인트를 제거한다" 와 "원천을 개인 프레스로 바꾼다" 는 **전환 기간 동안 보류돼요.** 제거 후 ADR-0031 의 상태로 돌아가므로 대체하지 않아요.
- 재검토: **최소 지원 앱 버전이 구버전을 배제하면** v2 상세와 프레스 엔드포인트 둘을 지우고 ADR-0031 의 구조로 돌아가요.
