# ADR-0035: 개발 서버 API를 Cloudflare 프록시 없이 직접 받는다

## Status

Proposed (2026-10-12)

개발 서버에서 먼저 바꿔 응답 시간을 재 보기 위한 구성이에요. 전환 뒤의 측정값과 운영 서버 적용 여부는 아직 정하지 않았어요.

## Context

- `api-dev.pheeeew.com` 과 `api.pheeeew.com` 은 Cloudflare 프록시를 거쳐요. 한국에서 보낸 요청이 해외 거점을 지나 한국 서버로 돌아와요.
- 2026-10-12에 한 회선에서 잰 값으로 `api-dev` 는 홍콩(HKG) 거점에 연결됐어요. 새 연결의 첫 요청은 0.31~0.51초, 같은 연결을 다시 쓴 요청은 0.08초였어요.
- DNS 조회와 TLS 인증은 연결마다 한 번이라 원인이 아니었어요. 요청과 응답이 매번 해외 거점을 왕복하는 것이 지연의 원인이에요.
- 개발 nginx는 Cloudflare Origin CA 인증서를 쓰고, Cloudflare가 아닌 접속을 거부하고, 요청자 주소를 `CF-Connecting-IP` 헤더에서 읽어요. 기기 등록과 challenge 발급의 요청 제한도 이 헤더를 기준으로 해요.
- 개발 서버의 스웨거는 Cloudflare Access로만 보호하고 있어요. Access는 프록시를 거친 요청에만 적용돼요.
- 앱(`an/dev`)은 인증서를 고정하지 않아요.

## Decision

개발 서버의 API 주소는 Cloudflare 프록시를 끄고 nginx가 Let's Encrypt 인증서로 직접 받아요. 스웨거는 프록시와 Access를 유지하는 문서용 주소 `docs-dev.pheeeew.com` 으로 옮기고 API 주소에서는 막아요. 요청자 주소는 연결 주소를 쓰고 Cloudflare 대역에서 온 연결만 `CF-Connecting-IP` 를 믿어요.

## Alternatives

- 프록시 유지 — 설정을 바꾸지 않아도 되지만 요청마다 해외 거점을 왕복하는 지연이 남아요.
- Cloudflare 유료 요금제 — 국내 거점으로 갈 가능성이 높아지지만 보장되지 않고 비용이 들어 검토에서 제외했어요.
- 스웨거에 nginx 기본 인증이나 IP 제한 — 주소를 늘리지 않아도 되지만 비밀번호 공유나 IP 관리가 필요하고 지금의 로그인 방식을 버려야 해 선택하지 않았어요.
- HTTP 방식 인증서 발급 — 프록시를 끈 뒤에만 발급할 수 있어 끊김 없는 전환이 어려워요. DNS 방식은 미리 발급할 수 있어요.

## Consequences

- (+) API 요청이 해외 거점을 거치지 않아요. 줄어드는 시간은 전환 뒤에 재요.
- (+) 새 설정은 프록시가 켜져 있어도 동작해요. 문제가 생기면 DNS 프록시를 다시 켜서 되돌려요.
- (-) 개발 서버의 IP가 공개되고 Cloudflare의 공격 방어와 봇 차단을 쓰지 못해요.
- (-) 인증서를 90일마다 갱신해야 해요. 갱신이 실패하면 앱의 모든 요청이 실패해요.
- (-) Cloudflare 주소 대역이 바뀌면 nginx의 목록을 손으로 고쳐야 해요. 고치지 않으면 문서용 주소로 온 요청의 요청자 주소가 Cloudflare 주소로 잡혀요.
- (=) DNS 편집 권한을 가진 Cloudflare API 토큰이 서버에 남아요. 문서용 주소와 Access 설정이 하나씩 늘어요.
- 재검토: 전환 뒤 응답 시간 차이가 작거나, 직접 받은 뒤 공격이나 비정상 요청이 늘거나, 운영 서버 적용을 정할 때 다시 판단해요.

## Compliance

- 임시 컨테이너에서 직접 연결의 요청자 주소, 위조한 `CF-Connecting-IP` 무시, Cloudflare 대역의 헤더 신뢰, API 주소의 스웨거 404, 문서용 주소의 Cloudflare 인증서 요구, 헤더 위조로 요청 제한을 우회하지 못하는 것을 확인했어요. 임시 인증서와 흉내 낸 앱으로 한 확인이에요.
- 실제 Cloudflare와 실제 인증서에서의 동작, 전환 전후 응답 시간은 배포 뒤에 확인해요.
- 발급, 갱신, 전환, 되돌리기 절차는 [nginx 안내](../../docker/nginx/README.md)에서 관리해요.
