# ADR-0028: 경계 밖 감정을 인접 지역에 배정하고 신규 등록 범위를 제한한다

## Status

Accepted (2026-10-05). 승인된 설계와 구현을 기록해요. 개발·운영의 정책 전환 완료를 뜻하지 않아요.

## Context

- SGIS 2025년 2분기 경계의 포함 판정만으로는 해안 근처의 일부 선택 좌표를 지역에 연결하지 못해요.
- 사용자가 위치를 선택할 수 있으므로 경계 밖 좌표가 항상 잘못된 요청인 것은 아니에요.
- [이슈 #618](https://github.com/woowacourse-teams/2026-pheeeew/issues/618)은 인접 지역 배정과 신규 등록 범위 제한을 요구해요.
- ADR-0027의 정상 미매칭 처리 중 인접 지역 배정과 신규 등록 정책을 변경해요. 집계·표시 계약은 유지해요.

## Decision

최종 저장 Point를 `ST_Covers`로 먼저 분류하고, 여러 읍면동에 포함되면 코드 오름차순으로 선택해요.
미매칭이면 `geography`의 타원체 기준 최단 거리로 가장 가까운 읍면동 폴리곤을 선택하되 1,000m 이하만 배정해요. 거리 동률은 코드 오름차순이에요.
좌표와 경계는 EPSG:4326으로 유지하고 이동·버퍼 보정하지 않아요. 앱과 백필은 같은 DB 분류 함수를 사용하며 EMD 경계의 geography GiST 인덱스로 거리 후보를 좁혀요.

신규 등록만 지역 미배정을 `EMOTION-014`·400으로 거부하며, 경계 미검증의 `EMOTION-013`·503과 구분해요.
기존 성공 requestId는 원래 결과를 반환하고 기존 범위 밖 감정·수정·삭제는 보존해요. 기기별 1초 제한은 기존 멱등 조회 앞에 유지해요.
좌표 검증과 그룹 확인 뒤, 녹음 확인·연결 전에 지역을 검사하며 기존 삽입 트랜잭션과 멱등 복구를 유지해요.

## Alternatives

- 포함 판정만 유지: 해안 인접 좌표를 집계에 연결하지 못해요.
- 제한 없이 최근접 지역 배정: 멀리 떨어진 해외 좌표도 국내 지역에 연결해요.
- 표시점까지의 거리 또는 위경도 평면 거리: 폴리곤 최단 거리와 미터 기준을 충족하지 못해요.
- 앱·백필에 SQL 각각 유지: 거리 기준과 동률 규칙이 달라질 수 있어요.

## Consequences

- (+) 해안 인접 기록을 기존 지역 계층과 집계에 포함할 수 있어요.
- (-) 추가 거리 조회와 인덱스 저장 공간이 필요하고 신규 등록의 허용 범위가 줄어요.
- (=) 국내 서비스 범위는 지정한 SGIS 경계와 1km 인접 범위예요. 사용자 실제 위치나 국내 법적 해역을 증명하지 않아요.
- (=) 기존 지역 코드가 NULL이고 새 규칙으로 배정 가능한 감정만 수동 재분류해요. 범위 밖 기록은 NULL 코드와 분류 시각을 보존해요.
- (=) 수동 전환 시작으로 집계 완료 표시를 해제하고, 전체 미분류·배정 가능한 NULL이 없음을 검증한 뒤 복구해요. 새 준비 검사부터 지역 집계는 503이며 이미 검사를 통과한 요청은 완료될 수 있어요.
- (=) 시작·배치·완료 검증은 같은 advisory 잠금을 사용해요. 배치의 0건은 완료를 뜻하지 않으며, 집계가 열린 상태의 실제 재분류는 거부해요. 완료 후 대상 없는 재시도는 완료 시각을 보존해요.
- (-) 완료 검증은 쓰기를 잠시 막으며 명령별 5초 제한이에요. 이후 구버전·직접 SQL의 미배정 재유입은 영구 차단하지 않아요. 구버전 등록과 진행 중 쓰기를 먼저 종료해요.
- 재검토: 경계 교체나 거리 정책 변경, 실제 자료의 분류 품질·비용이 요구를 충족하지 못하면 다시 판단해요.

## Compliance

- PostgreSQL 17 / PostGIS 3.5 Testcontainers로 포함 우선·거리 임계값·동률·실패 처리와 녹음 원자성·멱등성·재분류를 검증했어요. 시작·재분류·완료와 기존 집계 회귀 89건은 실패·오류·건너뜀 없이 통과했어요.
- 실제 SGIS 전국 경계와 합성 좌표 3,690개를 별도 로컬 DB에서 확인했어요. 인접 미매칭 2개가 배정되고 먼 좌표 3개는 제외됐어요. 실제 개발·운영 감정이나 실기기 성능의 검증 결과는 아니에요.
- 실제 자료 검증 범위와 [개발·운영 전환 절차](../../scripts/regions/README.md)는 별도로 기록해요. 개발·운영 데이터 변경과 배포는 대상별 승인을 받아요.
