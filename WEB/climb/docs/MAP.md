# 감정이들의 점프 대모험: 마음의 탑 맵 설계서

상태: 구간 1~2 구현됨. 구간 3~5는 개요입니다.

## 확정된 기획

- 장르: 모아서 점프하는 수직 등반. 공중에서는 방향을 바꿀 수 없습니다.
- 조작: 좌우 키로 걷기, 스페이스를 누르고 있으면 차지, 놓으면 점프. 최대 차지 0.8초.
- 최대 점프 높이는 화면 높이의 약 45%. 벽에 부딪히면 가로 속도가 절반이 되어 튕깁니다.
- 한 화면 넘게 떨어지면 엎어지고, 1.2초 뒤에 일어납니다.
- 길이: 5구간 × 6화면 + 정상 1화면 = 31화면.
- 카메라: 부드러운 세로 스크롤.
- 낙하 벌: 보통 실수는 1~2화면. 구간 관문에서만 3~5화면. 구간 시작 쉼터는 바닥이 막혀 있어 그 아래로는 떨어지지 않습니다.
- 감정이: 시작할 때 한 명을 고르고 끝까지 갑니다. 어느 감정이 하나만으로도 전체를 깰 수 있습니다.
- 플랫폼: 웹 PC, 키보드. 위치와 기록을 브라우저에 자동 저장합니다.

## 설계 단위

- 화면 1개 = 1280×720. 격자 1칸 = 40px. 화면 1개는 가로 32칸 × 세로 18칸입니다.
- 캐릭터 충돌 상자 = 가로 1.5칸 × 세로 1.2칸.
- 최대 점프 = 높이 8칸, 같은 높이로 착지할 때 가로 약 9칸.
- 최소 점프(톡 누름) = 높이 1.5칸.
- 발판 폭 등급: 넓음 6칸 이상, 보통 3~5칸, 좁음 2칸, 바늘 1.5칸.

## 감정이 고유 능력

모든 필수 점프를 5명 각각의 물리로 자동 검증합니다. 한 명이라도 못 가는 점프는 맵에 넣지 않습니다.

| 감정이 | 능력 | 대가 |
|---|---|---|
| 좌절이 (파랑) | 엎어져도 바로 일어납니다. | 없음. 가장 순한 선택입니다. |
| 지침이 (보라) | 떨어지는 속도가 느립니다. 내려올 때 궤적이 길어져 먼 발판에 닿습니다. | 같은 점프가 다른 감정이보다 멀리 가서, 좁은 발판을 넘기기 쉽습니다. |
| 답답이 (살구) | 공중에서 한 번 허우적대 가로 속도를 30% 줄이거나 늘립니다. | 허우적댄 점프는 착지 후 0.3초 동안 못 움직입니다. |
| 짜증이 (분홍) | 벽에 튕겨도 가로 속도의 85%가 남습니다. | 좁은 통로에서 여러 번 튕겨 제어가 어렵습니다. |
| 분노 (빨강) | 0.6초면 차지가 끝나고, 최대 점프가 10% 높습니다. | 차지가 빨라 세기를 맞추는 시간 창이 좁습니다. |

## 난이도 규칙

1. 구간마다 새 장치를 하나만 넣습니다. 구간 5만 예외로 둘입니다.
2. 구간 안의 순서는 소개 → 응용 → 조합 → 관문입니다. 소개 화면에서는 실패해도 같은 화면에 남습니다.
3. 필수 점프의 차지 허용 오차: 구간 1은 ±10%, 구간 2는 ±8%, 구간 3은 ±6%, 구간 4는 ±5%, 구간 5는 ±4%. 차지 시간으로 환산해 가장 좁은 곳도 0.05초 이상입니다.
4. 관문 직전에는 넓은 발판을 둡니다. 관문에서 떨어지는 경로 중간에는 좁은 턱을 1~2개 둡니다. 턱에 걸리면 덜 떨어지지만, 턱에서 올라오는 길은 원래 길보다 어렵습니다.
5. 떨어지는 곳마다 도착 지점을 정해 둡니다. 우연히 두 구간을 떨어지는 일은 없습니다.

## 맵 구조 원칙 (점프킹 계열 맵 조사 반영)

- 얇은 발판을 띄우지 않고, 두꺼운 지형 덩어리와 그 사이 빈 공간으로 만듭니다.
- 경사면은 구간 1부터 기본 지형입니다. 닿으면 서지 못하고 미끄러져 끝에서 날아갑니다.
- 여러 화면을 잇는 긴 미끄럼틀과 수직 통로를 두어, 실수하면 2~3화면을 떨어집니다.
- 머리 위 덩어리(낮은 천장)로 차지 세기의 상한을 만듭니다.
- 내려갔다가 다시 올라가는 길, 가장자리로 나와서 뛰어야 하는 곳을 섞습니다.
- 실제 배치는 `public/level.js`가 기준입니다. `node tools/validate.mjs --map`으로 글자 지도를 볼 수 있습니다.

## 정상 (화면 31)

히유~ 전망대. 넓은 바닥에 감정이 다섯이 모여 한숨을 돌립니다. 걸린 시간, 떨어진 횟수, 고른 감정이를 보여 줍니다.
