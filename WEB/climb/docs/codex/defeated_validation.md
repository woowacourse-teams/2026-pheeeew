# defeated 점프 자세 검수

- 생성 도구: built-in image_gen. 사용 프롬프트: defeated_prompts.json.
- 기준 몸통 폭: 780px. 허용 범위: 741~819px.
- 몸통 폭은 손발이 가리지 않는 가시 외곽선 구간에서 측정했다. 사용 구간과 배율은 defeated_measurements.json에 기록했다.
- 눌림 정도는 splat > charge > land 순서로 구분했다. 폭 ±5% 규격을 우선해 폭 확대를 제한했다.
- 기존 흰 눈물은 캐릭터 표정의 일부로 유지했다. 별도 땀방울이나 효과는 추가하지 않았다.
- 좌우 비대칭 자세의 정렬은 주문서 최종 검사 기준인 전체 알파 영역의 가로 중심을 사용했다.
- 생성본의 알파 1~7 잔여 픽셀만 0으로 정리했다. 종횡비를 유지한 배율 조정 후 정수 픽셀 이동으로 위치를 맞췄다.
- 모든 출력: 1024×1024 RGBA PNG, 네 모서리 알파 0, 최하단 y=900.
- 작업 시작 시점의 PNG와 public/*.js 65개 해시가 모두 유지됐다.
- refs의 정면·옆면·반측면·lineup을 먼저 열었고, 최종 check_defeated.png도 직접 열어 색·선·표정·크기를 비교했다.
