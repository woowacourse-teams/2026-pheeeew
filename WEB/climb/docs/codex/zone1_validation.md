## 직접 확인한 이미지

- `zone1_tile_rock.png`: 1024×1024, 2×2 반복.
- `zone1_tile_fabric.png`: 1024×1024, 2×2 반복. 초기 솔기 어긋남을 발견해 주기·각도를 정렬하고 다시 확인했다.
- `zone1_tile_trim.png`: 1536×128, 가로 3회 반복.
- `zone1_tile_bg.png`: 1024×3072, 세로 2회 반복.
- `check_zone1.png`: 9장과 `refs/lineup.png`에서 자른 파란 좌절이. 아래에는 재질 256px·캐릭터 폭 75px의 합성 배치 예시를 넣었다. 합성 예시는 게임 실행 화면이 아니다.

반복 경계를 직접 확인했고, 지정된 반복 방향의 양 끝 픽셀 값 차이도 모두 0이다. 픽셀 일치는 시각 검사를 대신하지 않으며 두 검사를 함께 수행했다. 원래 있던 PNG와 `public/*.js` 총 119개의 SHA-256이 제작 전과 동일하다.

## 문서에 따라 정한 사항

1. 재질에는 외곽선을 추가하지 않았다. 소품은 어두운 손그림 외곽선과 수채화 질감을 사용했다.
2. 천의 솔기는 45도 방향으로 정렬하고 타일 한 변에 두 주기가 들어가게 잘라 경계에서 이어지도록 했다. 물방울 반짝임은 유지했다.
3. 소품은 비율을 유지해 크기와 기준점을 맞췄다. 종이배의 바닥 기준에는 작은 수면 물결을 포함했다. 표지판에는 짧은 골판지 받침을 사용했다.
4. 빗방울은 허용 범위 안에서 4개로 정했다. 생성 이미지의 거의 보이지 않는 알파 1~7 잔여 픽셀만 제거했다.
5. 밤의 분위기보다 명시된 밝은 배경·낮은 대비 규격을 우선했다. 발판 띠는 아래쪽 알파를 점진적으로 줄여 지형 위에 겹쳐도 밝은 띠가 두드러지지 않게 했다.

## 재현 및 기록

- 생성 프롬프트: `zone1_prompts.json`
- 생성 원본 경로: `zone1_sources.json` (도구가 자동 저장한 `$CODEX_HOME/generated_images/` 원본)
- 크기·알파·경계 측정: `zone1_measurements.json`
- 기존 파일 보존 기준: `zone1_original_hashes.json`
- 정렬 및 확인 그림 스크립트: `tools/prepare_zone1.py`

```sh
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=tools/.image-work/deps python3 tools/prepare_zone1.py
```
