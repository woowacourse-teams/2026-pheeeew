# 크리스마스 마을 그림 30장

완료: `public/assets/xmas/`에 기본 6장, `kit/`에 장식 24장 저장.

## 확인 그림

- `check_xmas.png`: 900×300 과자 벽, 눈 띠, top 6종, hang 5종, 양쪽 side 4종, in 6종, far 3종, 사탕 경사, 표지판과 마시멜로 발판.
- 재질과 모든 장식은 50% 크기. 원경도 768→384. 캐릭터는 `refs/lineup.png`의 파란 캐릭터를 직접 추출해 폭 75px로 배치.
- `xmas_contact_sheet.png`: 최종 30장 전체 보기.
- `xmas_tile_rock.png`, `xmas_tile_fabric.png`: 각각 2×2 반복.
- `xmas_tile_trim.png`: 가로 3번, `xmas_tile_bg.png`: 세로 2번 반복.

위 그림을 직접 열어 최종 배치와 반복 경계를 확인했다. 사탕 줄무늬의 최초 경계 교차를 수정하고 다시 확인했다.

## 문서에 따라 정한 세부 사항

1. 배경은 밤 분위기를 유지하면서 지정 평균색 `#c9d2ee`에 맞춘 밝고 흐릿한 남보라로 처리했다. 원경은 더 옅은 반투명 수채화로 낮췄다.
2. 눈 띠는 윗면 y=40, 실제 위로 솟는 높이는 최대 14px. 아래로 갈수록 알파가 줄어들며 마지막 행은 완전 투명하다.
3. top 장식은 자연스러운 물체 비율을 유지했다. 젤리·등불처럼 폭이 좁은 물체에는 낮은 눈 받침을 더해 전체 폭 120~240px 조건을 맞췄다.
4. 접합부는 과자 벽 평균색으로 연결했다. y=200 / y=56 / x=56 기준선에서 벽 색과 일치하고 지형 내부 방향으로 알파가 0까지 감소한다. 왼쪽 side 배치는 좌우 반전한다.
5. 사탕 재질은 생성 원본에서 측정한 128px 줄무늬 주기를 이용해 동일 위상의 구간을 겹쳐 연결했다. 원본 수채화 질감과 윤기를 유지하면서 반복 경계의 교차를 제거했다.

## 검증

`node tools/verify_xmas.cjs` 실행 결과: 통과.

- 30장 파일 수와 모든 캔버스 크기 검사.
- 불투명 3장과 투명 27장, 투명 여백, 접합 위치·색, 장식 폭·높이·중심 검사.
- rock/fabric 양방향, trim 좌우, bg 상하의 맞닿는 픽셀 차이 0.
- nod: 480×200, 몸통 x=1~478 / y=20~179. 표지판 바닥 y=450, (256,450)에 실제 픽셀 존재.
- 기존 PNG 해시 변경 없음. 이 작업에서는 `public/*.js`를 수정하지 않았다. 생성 도중 `main.js`, `rig.js`의 외부 변경이 관측되어 그대로 보존했다.

수치 결과: `xmas_work/checks.json`, 개별 규격: `xmas_work/validation.json`, 배치: `xmas_work/placements.json`.

## 제작 기록

내장 `image_gen` 사용. 파일별 별도 생성 후 Sharp로 규격·접합·반복을 정리했다. 창문 `in_4`는 추가 이미지 편집으로 불필요한 집 모양 배경을 제거했다.

프롬프트: `xmas_work/prompts.json`. 생성 원본 경로: `xmas_work/sources.json`. 준비 스크립트: `tools/prepare_xmas.cjs`.

프로젝트 밖에는 파일을 작성하지 않았으며, 이미지 도구가 자동 저장한 `$CODEX_HOME/generated_images/` 원본만 예외이다. 게임 실행 코드 연결은 변경하지 않았다.
