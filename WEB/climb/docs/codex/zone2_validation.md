# 구간 2 지침의 밤 — 제작 및 검증

`public/assets/zone2/`에 PNG 10장을 저장했다. 내장 `image_gen`으로 각 원화를 생성하고, 요청된 규격 정렬·반복 경계 보정·확인 그림 합성은 Pillow로 수행했다. 먼저 구간 1 재질·띠·배경 4장과 캐릭터 lineup, umbrella, tissue_box, leaky_bottle을 직접 열어 확인했다.

일반 소품의 가로 중심은 x=256이며 생성 원화의 비율을 유지했다. 알파 1~7의 거의 보이지 않는 생성 잔여 픽셀을 제거했다. 투명 이미지 7장은 모두 실제 알파 최솟값 0·최댓값 255를 가진다.

## 직접 열어 확인한 결과

- `zone2_tile_rock.png`: 1024×1024, 2×2 반복. 두드러진 인쇄 무늬를 원화 수정으로 제거했고, 낮은 대비의 주름과 누빔만 남겼다.
- `zone2_tile_fabric.png`: 1024×1024, 2×2 반복. 대각선 주기를 측정해 맞춘 뒤 가장자리를 겹쳐 보정했다. 최종 타일 한 변에 두 주기가 들어간다.
- `zone2_tile_trim.png`: 1536×128, 가로 3회 반복. 솔기와 프린지가 이어지며 아래로 흐려진다.
- `zone2_tile_bg.png`: 1024×3072, 세로 2회 반복. 위아래 연결부에 뚜렷한 색 경계가 없다.
- `check_zone2.png`: 10장 전체와 `refs/lineup.png`에서 자른 지침이. 아래에는 재질 256px·캐릭터 폭 75px로 합성한 크기 비교를 넣었다. 실제 게임 실행 화면은 아니다.

검사 그림 5장을 직접 열어 확인했고, 합성 배치의 소품 겹침을 정리한 뒤 최종 모음 그림과 꾸벅 발판도 다시 열었다. 지정된 반복 방향의 양 끝 픽셀 차이는 모두 0이다. 수치 검사와 육안 검사를 함께 수행했다.

## 문서에 따라 정한 사항

1. 책은 5권, 모빌은 달 1개와 별 3개로 구성했다. 시계는 숫자 대신 눈금으로 3시를 읽게 했다.
2. 꾸벅 발판에는 글자 대신 감긴 눈 자수를 사용했다. 생성된 질감과 외곽선을 유지하면서 각 세로 열의 윗면을 y=20에 정렬했다.
3. 밤의 어두움보다 명시된 밝은 배경·낮은 대비를 우선했다. 배경 평균 RGB는 약 (231,216,244), 지형은 (143,132,169)다.
4. 포스트잇 주변의 원치 않는 번짐은 이미지 생성 도구로 제거했다. 재질에는 검정 외곽선을 넣지 않았고, 소품은 어두운 손그림 외곽선을 사용했다.
5. 기존 PNG 129장의 SHA-256은 모두 작업 시작 때와 같다. 이 작업에서는 `public/*.js`를 쓰지 않았다. 다만 작업 중 `public/level.js`, `public/main.js`의 해시 변경을 감지했으므로 전체 JS가 그대로라는 보장은 하지 않는다. 해당 파일을 되돌리거나 수정하지 않았다.

꾸벅 발판의 2초 뒤 꺼지는 동작은 이번 이미지 제작의 검증 대상이 아니다.

## 기록 및 재현

- `zone2_prompts.json`: 내장 도구에 보낸 원화 10장 및 수정 2장의 프롬프트.
- `zone2_sources.json`: 선택된 생성 원본 10장의 자동 저장 경로.
- `zone2_measurements.json`: 크기·알파·기준점·반복 경계·기존 파일 측정 결과.
- `zone2_original_hashes.json`: 작업 시작 시 기존 PNG 및 public JS 해시.
- `tools/prepare_zone2.py`: 규격 정렬과 검사 그림 생성 스크립트. 기존 zone1 스크립트의 순수 이미지 보조 함수를 읽어 재사용한다.

생성 도구의 자동 저장을 제외한 모든 새 파일은 이 프로젝트 안에 있다.

```sh
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=tools/.image-work/deps python3 tools/prepare_zone2.py
```
