# 구간 1 "뉴욕 빌딩 숲" 그림 주문서

## 테마
**해 질 녘 뉴욕의 빌딩 숲.** 캐릭터가 골목 바닥에서 시작해 벽돌 건물 사이를 뛰어 옥상까지 오릅니다. 지형 덩어리 하나하나가 건물입니다. 활기차고 따뜻합니다.
색: 따뜻한 벽돌색과 노을빛(주황·분홍·보라)이 중심, 켜진 창문의 노랑이 포인트. 지형 외곽선 색은 어두운 적갈색(#3b2a2e).
저장 위치: `public/assets/nyc/` (장식은 `public/assets/nyc/kit/`). 확인 그림: `docs/codex/check_nyc.png`.
