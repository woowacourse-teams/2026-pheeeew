# 구간 1 "좌절의 웅덩이" 맵 그림 주문서

## 게임과 컨셉
피유(Pheeeew) 감정 캐릭터가 탑을 오르는 2D 옆에서 보는 등반 게임입니다. 구간 1의 주인은 파란 감정 캐릭터 "좌절이"입니다.

컨셉: **비 오는 밤, 눈물에 잠긴 방.** 좌절한 마음속 풍경입니다. 젖어서 굳은 종이 상자와 휴지 상자가 절벽처럼 쌓여 있고, 뒤집힌 우산이 미끄럼틀이 됩니다. 슬프지만 귀엽고 포근해야 합니다. 무섭거나 더럽게 그리지 않습니다.

색: 차분한 파랑·회청색이 중심이고, 우산 천의 분홍과 창문 불빛의 따뜻한 노랑이 포인트입니다.

## 그림체 (반드시 먼저 열어 봅니다)
- `refs/lineup.png` 캐릭터 5명. 굵은 검정 외곽선 + 수채화 질감 채색.
- `refs/props/umbrella.png`, `refs/props/tissue_box.png`, `refs/props/leaky_bottle.png` 기존 소품.
새 그림은 이 그림들과 한 세트로 보여야 합니다. 같은 수채화 질감, 같은 채도, 같은 손그림 느낌입니다.

## 그릴 것 9장 (저장 위치: `public/assets/zone1/`)

### A. 이어 붙이는 재질 2장 — 가장 중요
게임이 지형 모양대로 잘라서 반복해 붙입니다. 외곽선은 게임 코드가 따로 그립니다.
- 512×512 PNG, 불투명. 상하좌우로 이어 붙였을 때 **이음매가 보이지 않아야** 합니다.
- 큰 그림자, 한쪽으로 치우친 빛, 눈에 띄는 한 개짜리 무늬를 넣지 않습니다(반복이 티 납니다).
- 화면에는 절반 크기(256px)로 보입니다. 캐릭터는 약 75px 폭입니다. 무늬가 너무 잘면 뭉개지고 너무 크면 반복이 보입니다.

| 파일 | 내용 |
|---|---|
| `rock.png` | 지형 덩어리의 속. 젖은 골판지와 종이 상자가 겹겹이 눌려 굳은 면. 회청색(#6f8fae 근처, 캐릭터보다 어둡고 채도 낮게). 상자 이음선, 붙였던 테이프 자국, 물 얼룩이 은은하게 보임. 캐릭터와 발판 윗면이 잘 보이도록 대비를 낮게. |
| `fabric.png` | 미끄러운 경사면의 속. 젖은 우산 천. 분홍(#f2a9b4 근처)에 남색 솔기 줄이 대각선으로 지나감. 물방울이 맺혀 반짝임. 한눈에 "미끄럽다"가 읽혀야 합니다. |

### B. 윗면 장식 띠 1장
- `trim.png`: 512×128 PNG, 투명 배경. 좌우로 이어 붙였을 때 이음매가 없어야 합니다.
- 발판 윗면에 얹는 띠입니다. 그림의 y=32 줄이 발판의 윗면 선입니다. 그 위(0~32)에는 고인 물의 얇은 반짝임과 작은 물결, 그 아래(32~128)에는 젖어서 진해진 가장자리와 흘러내리는 물 자국 몇 줄을 그립니다. 아래로 갈수록 투명해집니다.

### C. 배경 1장
- `bg.png`: 1024×1536 PNG, 불투명. 위아래로 이어 붙였을 때 이음매가 없어야 합니다(세로로 계속 스크롤됩니다).
- 내용: 밤의 큰 유리창 벽. 유리에 빗줄기와 흘러내리는 물방울, 멀리 번진 도시 불빛(따뜻한 노랑 점), 창틀이 드문드문.
- 지형과 캐릭터 뒤에 깔립니다. **밝고 흐릿하게**(연한 하늘색 #cfe3f2 근처가 평균색), 대비를 아주 낮게 그립니다. 굵은 검정 외곽선을 쓰지 않습니다.

### D. 장식 소품 5장
- 각 512×512 PNG, 투명 배경. 소품의 바닥 중앙이 (256, 450)에 옵니다(기존 소품과 같은 규격).
- 굵은 검정 외곽선 + 수채화 채색. 옆에서 본 모습.

| 파일 | 내용 |
|---|---|
| `puddle.png` | 바닥에 고인 작은 물웅덩이. 물결과 반짝임. 폭 약 300px. |
| `drips.png` | 천장에서 떨어지는 물방울 3~4개가 세로로 줄지은 모습. 이 그림만 기준점이 위쪽입니다: 맨 위 물방울이 (256, 60)에 옵니다. |
| `tissue_pile.png` | 구겨진 휴지 뭉치 더미. 폭 약 260px. |
| `paper_boat.png` | 물에 뜬 종이배. 폭 약 220px. |
| `arrow_sign.png` | 젖은 골판지 조각에 크레파스로 그린 화살표. **화살표는 오른쪽 위를 가리킵니다.** 글자는 넣지 않습니다. 폭 약 220px. |

## 끝내기 전에 직접 확인할 것
1. `rock.png`, `fabric.png`를 각각 2×2로 이어 붙인 확인 그림을 `docs/codex/zone1_tile_rock.png`, `docs/codex/zone1_tile_fabric.png`로 저장하고 직접 열어 봅니다. 이음매나 반복 무늬가 눈에 띄면 고칩니다(가장자리를 옮겨 붙이고 다듬는 방법을 써도 됩니다).
2. `trim.png`를 가로로 3번, `bg.png`를 세로로 2번 이어 붙여 같은 방식으로 확인합니다(`docs/codex/zone1_tile_trim.png`, `docs/codex/zone1_tile_bg.png`).
3. 9장 전부와 `refs/lineup.png`의 캐릭터 하나를 한 장에 모은 확인 그림을 `docs/codex/check_zone1.png`로 저장합니다. 캐릭터와 한 세트로 보이는지 직접 봅니다.
4. 크기와 투명 여부가 위 규격과 같은지 확인합니다.
5. 이 폴더(`pheeeew-climb`) 밖의 파일은 만들거나 고치지 않습니다. 예외: 이미지 생성 도구가 `$CODEX_HOME/generated_images/` 아래에 자동으로 저장하는 것은 괜찮습니다. `public/*.js`와 기존 PNG는 고치지 않습니다.
6. 중간에 질문하지 말고 끝까지 진행합니다. 판단이 필요하면 이 문서의 규격을 우선해 스스로 정하고, 마지막 답에 무엇을 정했는지 적습니다.
