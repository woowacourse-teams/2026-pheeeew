# 구간 4 설계 메모 (열기구 축제 하늘, 내 높이 0~126, 화면 7장)

파일: `public/zones/zone4.js`. `export const top = 126`. 검증: `ZONE=4 node tools/validate.mjs --all --skips`.
높이는 "내 시작 바닥이 0" 기준입니다. 창 단위는 틱(1/120초)입니다. 값은 2026-11-12 규칙 변경(5명 능력 동일) 뒤의 계산값입니다.

## 큰 구조

- **왼쪽 낙하 통로** (칸 1~6, 높이 38~124): 화면 4 병목과 관문에서 넘치면 받이 턱(높이 38)까지 떨어집니다.
- **갑판** (높이 56, 칸 8~24): 화면 4·5의 실수를 받습니다. 오른쪽 구멍(칸 25~30) 밑은 받이 발판(높이 52)이 막습니다.
- **축제 마당** (높이 20, 칸 5~30): 화면 2의 바닥이고, 화면 3의 실수가 떨어지는 곳입니다.
- **꼭대기 갑판** (높이 122, 칸 16~30): 쉼터(칸 1~14)와 틈이 1칸이라 쉼터에서 오른쪽으로 떨어져도 4칸 아래에서 멈춥니다.

## 2차 수정 (심사 `review2.md` 반영)

- **관문을 다시 짰습니다.** 작은 바구니와 깃대 발판을 없앴습니다. 오른쪽(바람 없음)으로 바구니(106) → 1칸 바구니(110) → 발사대(113)를 오른 뒤, 왼쪽으로 뛰어 순풍 속 1칸 발판(118)에 내립니다. 이 점프가 구간에서 가장 좁고(창 7), 모자라면 넓은 바닥(90)으로 28칸, 넘치면 왼쪽 통로로 80칸입니다. 발사대 어느 자리에서든 끝까지 누르면 넘칩니다. 제자리 점프 지름길은 없습니다.
- 꼭대기 갑판에 턱(칸 17)을 넣었습니다. 1칸 바구니 오른쪽에 받이(105)를 넣었습니다(넘쳐도 5칸).
- 화면 3: 바구니를 49로 올리고 칸 24~25로 옮겼습니다. 풍선 꼭대기에서 바로 가는 끝까지 누르기 점프가 없어졌습니다. 받이 발판은 52입니다.
- 화면 4: 갑판 위 상자를 1칸(58)으로 줄였고, 깃발 줄 다리를 3칸(칸 15~17)으로 줄였습니다.
- 화면 6: 바람을 없앴습니다(상한이 생기도록).
- 화면 1: 창을 22~45로 줄였습니다. 아래 갑판 왼쪽 끝에서 제자리 점프로 위 갑판에 실려 가는 길(창 27)이 본 길에 들어갔습니다.

## 바람으로 만든 것

- **제자리 점프가 실려 감** (화면 1): 아래 갑판 왼쪽 끝(칸 15)에서 방향키 없이 뛰면 위 갑판에 내립니다(창 27, 본 길). 오른쪽 끝에서는 바구니 2에 내립니다.
- **맞바람 속 더 센 점프**: 화면 1 바구니 2(5칸 위), 화면 2의 건너뛰기, 화면 4 큰 바구니.
- **순풍에 넘치는 좁은 착지**: 화면 3 구름, 화면 5 풍선 꼭대기, 관문 1칸 발판.
- **경계를 걸친 점프**: 화면 2 구름 → 바람 밖 바구니, 바람 밖 바구니 → 구름 2칸, 화면 5 풍선 → 바람 밖 구름, 관문 발사대 → 1칸 발판(칸 18부터 밀림).
- **바람과 경사**: 화면 3·5의 풍선(양옆 경사), 화면 4의 바구니(바깥으로 기운 테).
- **바람이 끌고 가는 낙하**: 관문의 1칸 발판에서 넘치면 바람이 왼쪽 통로까지 밀어 높이 38에 떨어집니다.

## 바구니 (지형 조합)

바닥 위 양 끝에 바깥으로 기운 경사 칸을 올렸습니다. 테에 내리면 바깥으로 미끄러집니다. 안쪽에서 테는 벽이라, 나올 때는 세게 뛰어 테를 넘어야 합니다. 화면 4에 하나 있습니다(안쪽 바닥 3칸).

## 지름길

- 본 길보다 넓은 지름길은 없습니다. 검증기가 제자리 점프까지 계산한 결과입니다.
- 7칸 오르는 끝까지 누르기 점프(창 7~8)가 남아 있습니다: 마당 → 구름 1칸, 구름 2칸 → 풍선 꼭대기, 구름(45) → 받이 발판, 갑판 → 깃대 발판, 관문 바구니(106) → 발사대. 어느 것도 병목(화면 3·4·5, 관문)을 건너뛰지 않습니다.

## 알려진 한계

- 상한 비율: 본 길 35개 중 엄격 기준 15개(43%), 가장 넓은 자리 기준 18개(51%). 목표 55%(엄격)에 못 미칩니다. 남은 20개는 대부분 넓은 받이 바닥에서 뛰거나 내리는 점프이고, 나머지는 벽에 붙은 발판, 맞바람 점프, 머리를 박고 떨어져 닿는 자리가 있는 점프입니다(종류별 개수는 세지 않았습니다).
- 화면 4 병목은 모자라면 제자리입니다(넘치면 29칸).
- 꼭대기 갑판: 쉼터에서 떨어진 사람은 턱 위나 턱 오른쪽에 섭니다. 턱 위에서 왼쪽으로 계속 걸으면 19칸 떨어집니다. 턱 왼쪽 주머니(칸 14.6~15.4)는 관문의 마지막 디딤이라 뚫려 있고, 거기서 왼쪽으로 뛰면 최대 84칸입니다.
- 화면 5의 작은 풍선 꼭대기 → 벽 쪽 바구니(창 51)는 모자라면 31칸입니다(고치지 않음).
- 경사가 벽·덩어리 2칸 안에서 끝나면 물리상 그 자리에 끼여 섭니다(2026-11-12 물리 수정 전에는 끝없이 튕겼습니다). 검증기는 이것을 "끼여 선 점프"로 실패 처리합니다. 지금 맵에는 없습니다.
- 시작 바닥 오른쪽(칸 15~30)은 구간 3의 영역입니다.
- 계산값이고 사람이 직접 해 보지 않았습니다. 꾸벅 구름은 늘 있는 것으로 계산했습니다.
