# USB Galaxy S10 5G 재측정

2026-10-18 동일 기기에 전후 각3회 새로 설치하고 재실행했다. 상세 설정과 APK SHA는 ../799-post-wait-device/README.md를 따른다. 기존 APK를 재사용했으며 소스를 새로 빌드하지 않았다. driver=viewmodel, 실제 화면과 실제 api-dev 서버를 사용한다. 물리 터치·렌더링 프레임 측정은 아니다.

연속 입력600회: POST89→104, 검증용 조회를 포함한 POST+GET125→191. 회차별 확인p95 범위743~845→570~636ms. 24개 조건 전체 입력1236회와 서버 증가1236회 일치. 단발과5회 연타도 각3회 포함했다. 원본은 logs/*.console.txt이며 python3 analyze.py로 CSV를 재생성한다. 로컬 설치 드라이버의 APK 절대경로는 당시 실행환경 기준이다.

이전 측정과 합쳐 평균내지 않았다. 이번에도 확인 지연 감소와 요청 증가가 재현되어, 조회 빈도 개선이 필요하다는 결론을 유지한다. 단일 사용자 Debug 측정으로 다중 사용자 처리량이나 실제 애니메이션 지연을 입증하지 않는다.

### 원본 무결성 확인

`analyze.py`는 분석 전에 기존 `SHA256.json`과 원본 로그·콘솔 출력·기기 정보·화면 및 저장된 테스트 결과를 비교한다. 누락 또는 불일치하면 실패하며 매니페스트는 덮어쓰지 않는다. 재생성하는 `comparison.csv`와 수정 가능한 설명 문서 `README.md`, 분석 코드 `analyze.py`는 원본 검증 대상에서 제외한다. 임의로 추가된 `.DS_Store` 등은 매니페스트에 등록하지 않는다.
