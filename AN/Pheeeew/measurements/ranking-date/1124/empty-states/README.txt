빈 랭킹 화면 구현 — 2026-11-06 KST

구현 및 연결된 iPhone 17 Pro USB 설치·앱 실행 완료.
- 내 기록만 없음: 연노란 캐릭터 안내 카드 아래 전체 순위 유지.
- 전체 기록 없음: 내 카드·배너·빈 표를 중복 표시하지 않고 캐릭터/트랙 중심 단일 안내 표시.
- 과거 전체 빈 결과: 다른 날짜 보기 → 기존 달력, 오늘 랭킹으로 돌아가기 → 실시간 모드.
- 오늘 빈 결과: 프레스 하러 가기와 다른 날짜 보기 제공.
- 전체 빈 화면에서도 당겨서 새로고침 및 갱신 실패 안내 유지.
- 로딩/오류를 빈 결과로 취급하지 않음.
- 큰 글씨/좁은 폭은 개인 안내 카드 세로 배치, 전체 안내는 스크롤 가능.

검증
- 공통 Android host 테스트 839개 통과. 실패/오류/스킵 0.
- 내 기록만 없음/전체 기록 없음 모두 정상 조회이며 참가자 목록을 보존하는 테스트 추가.
- ktlintFormat, Android lintDebug/assembleDebug 통과. android-checks.log 참고.
- Xcode Debug 기기 빌드 성공, devicectl USB 설치 및 실행 성공 (13:40 KST).
- 실제 iPhone에서 두 빈 상태의 화면 및 버튼을 직접 조작한 검증은 아직 하지 않음.
