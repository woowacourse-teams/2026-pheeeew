PR #1133 스크롤 리뷰 반영 — 2026-11-06

결과: 개요와 참가자 목록을 하나의 LazyColumn에 배치하여 안내 카드가 목록의 표시 높이를 모두 차지하는 문제를 수정했다.
날짜 선택 줄은 고정하고 배너, 내 카드, 목록 제목, 참가자 행을 함께 스크롤한다.
개요 영역에서도 당겨서 새로고침을 사용할 수 있다.

검증
- Android SM-G977N / Android 12, 화면 영역 320×400dp, 글씨 배율 2배.
- 참가자 1명, 내 기록 없음, 과거 조회 상태의 화면 테스트 1개 통과.
- 내 기록 없음 안내 표시 후 스크롤하여 참가자 행의 접근성 노드를 찾았다.
- 공통 host 테스트 839개 통과. 실패/오류/스킵 0.
- ktlintFormat, Android lintDebug, assembleDebug 및 기기 테스트 APK 빌드 통과.
- 상세 실행 기록: android-checks.log, scroll-test.log.

범위와 한계
- 이번 회귀 검증은 실제 제품 화면에 고정 상태를 전달했다. 실제 서버 조회 검증은 아니다.
- iPhone 재설치 및 수정 후 iOS 렌더링은 수행하지 않았다.
- 이번 변경은 스크롤 결함 및 화면 수준 검증 제안에 대응한다.
- 리뷰의 미확인 자정 재조회 의견과 문서 주석 커버리지 경고는 이번 수정에 포함하지 않았다.
