실험·검증 자료 안내

이 폴더는 제품 소스가 아니라 원본 측정 자료, 분석 스크립트와 결과를 보관한다.
각 실험의 기준 커밋·기기·가짜 응답 여부·관찰 한계는 해당 README를 먼저 확인한다.
과거 실기기 수치를 최신 구현의 검증 결과로 해석하지 않는다.

personal-press/644-baseline/  #644 개선 전 개인 프레스 기준 측정·장애·UI 실험
personal-press/799/           #799 묶음 대기·POST 대기·집계 조회 개선의 단계별 비교
text-input/815-ios/           #815 iOS 입력 검증 JSON과 해시
loading/820/                 #820 로딩 고정 대기 제거 가상 시간 비교
refactoring/844/             #844 책임 분리 전후 회귀 테스트·프로브 동일성

개인 프레스 자료는 personal-press/README.txt와 799/README.txt에서 실험 순서를 안내한다.
로그·CSV·XML·이미지·해시·분석 코드의 내용은 경로 정리 과정에서 변경하지 않았다.
Markdown 문서의 로컬 링크와 재분석 경로만 새 위치로 갱신했다.
이미지 추가·원본 삭제·Git 해시 목록 재생성은 하지 않았다.
원격의 과거 브랜치·커밋을 가리키는 링크는 당시 경로를 유지한다.

저장 로그 재분석은 기기 연결 없이 수행할 수 있다.
새 실험 실행은 서버 데이터 생성 또는 기기 네트워크 변경을 포함할 수 있으므로
개별 문서의 실행 조건과 대상 환경을 확인한다.
